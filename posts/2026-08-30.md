## Claude Code · Changelog

**版本號 / 日期：** 2.1.251 / August 28, 2026

**變更項目：**
- Added PreModelSwitch and PostModelSwitch hook events（新增模型切換前後的 hook 事件,可以攔截、確認或標註一次模型切換）
- Added live streaming of a foreground subagent's tool calls and results to Remote Control clients（前景 subagent 的工具呼叫與結果現在會即時串流到 Remote Control 遠端裝置,背景 subagent 預設仍只顯示狀態）
- Added a Spend limit bar to `/usage` and a `rate_limits.spend_limit` status line field（針對走 gateway 且有花費上限的企業用戶,`/usage` 新增花費額度條,status line 也能顯示對應欄位）
- Added a per-session prompt-cache line to `/cost`（`/cost` 新增每個 session 的 prompt cache 命中率、未命中數、重新快取 token 數等資訊,並提供對應的 `prompt_cache` 物件給 status line script 使用）
- Added `attach`, `logs`, `stop`, `respawn`, `rm` 到 `claude --help`（背景 session 的管理指令更完整,`--resume` 訊息現在會直接告訴你正確的 `claude attach <id>` 指令）
- Fixed a symlink-swap vulnerability in file tools（Read/Write/Edit 工具在權限檢查後,若工作目錄內的 symlink 被替換,可能讀寫到核准範圍外的位置,現已修正——屬安全性修補）
- Fixed plugin marketplace path-traversal issue（marketplace 中宣告的 plugin 指令若指向 plugin 目錄以外的路徑,現在會被拒絕並回報 path-traversal 錯誤）
- Fixed Opus 5 requests failing when effort was xhigh/max with thinking disabled（原本會噴出「effort … is not supported when thinking is disabled」錯誤,現在會自動改送 high）
- Fixed TUI lag with many parallel subagents（大量平行 subagent 時,每秒進度更新現在會取代前一則而非持續堆疊在 transcript 裡,改善終端機效能）
- Improved CPU usage during turns in interactive sessions（減少多餘的 UI 重新渲染,降低互動式 session 執行期間的 CPU 使用率）
- Improved install size（原生執行檔縮小約 5 MB）
- Changed `/effort` to save your default effort level per model（每個模型現在會各自記住自己的 effort 設定,切換模型不會互相覆蓋）
- Changed the default model for seat-based Enterprise subscriptions to Opus 5（企業版預設模型改為 Opus 5,與其他付費方案一致）
- [VSCode] Changed the Remote Control banner to a footer pill（VSCode 擴充套件的 Remote Control 提示從橫幅改成頁尾小標籤,點擊可在 claude.ai/code 開啟該 session）

**核心概念（簡單說）：**
這個版本的重點分成三類:一是「可觀測性 / 遠端操作增強」——新增模型切換 hook、Remote Control 即時串流前景 subagent 動作、`/cost` 顯示 prompt cache 細節,讓你更清楚知道 Claude Code 背後在做什麼、花了多少錢;二是「安全性修補」——修掉了兩個檔案系統層級的漏洞（symlink 替換繞過權限檢查、plugin 路徑穿越）,這類修補通常代表官方在強化多人協作或不完全信任環境下使用 Claude Code 的安全邊界;三是「效能與體驗微調」——TUI 效能、CPU 使用率、安裝檔大小都有改善,加上 `/effort` 現在能针對不同模型記住不同設定,减少切換模型時要重新調整參數的麻煩。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你會用多個 subagent 平行處理任務（例如同時跑測試、寫程式、查資料）,TUI lag 修正與即時串流到 Remote Control 這兩項改善會直接影響你日常操作的流暢度。
- **具體場景：** 在遠端裝置（手機或另一台電腦）用 Remote Control 監看正在 CI 環境或伺服器上跑的 Claude Code session 時,現在能即時看到前景 subagent 實際在呼叫哪些工具、跑出什麼結果,而不是只看到一個「執行中」的狀態,方便你判斷是否要介入。
- **這週可以嘗試：** 更新到 2.1.251 後,執行 `/cost` 看看新增的 prompt-cache 命中率資訊,評估目前的工作流程是否有效利用了 prompt caching,以及是否能透過調整 session 開頭固定內容的順序來提高快取命中率、降低費用。
