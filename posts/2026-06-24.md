## Claude Code · Changelog

**版本號 / 日期：** v2.1.187 / June 23, 2026

**變更項目：**
- Added `sandbox.credentials` setting（新功能）— 阻止沙盒指令讀取 credential 檔案和機密環境變數
- Added org-configured model restrictions（新功能）— 組織可限制可用模型，限制訊息出現在 model picker、`--model`、`/model`、`ANTHROPIC_MODEL` 等處
- Added mouse click support to select menus in fullscreen mode（新功能）— 全螢幕模式下可用滑鼠點選 permission prompts、`/model`、`/config` 等選單
- Fixed `--resume` failing with "No conversation found"（修復）— 修復當原始 `-p` run 沒有產生 model turns 時，`--resume` 回報找不到對話的問題
- Fixed `--json-schema` / `workflow agent({schema})` structured output loop（修復）— 修復 model 成功呼叫 StructuredOutput 後仍持續重複呼叫的問題，後續 turns 現在也能正確回傳 structured output
- Fixed remote MCP tool calls hanging 5 minutes（修復）— 修復 remote MCP 工具無回應時阻塞長達 5 分鐘的問題，現在會主動中止並報錯
- Fixed JetBrains IDE terminal flickering（修復）— 修復 IntelliJ、PyCharm、WebStorm 等 IDE terminal 的閃爍問題
- Fixed Shift+non-ASCII character input being dropped（修復）— 修復在使用 Kitty keyboard protocol（WezTerm、Ghostty、kitty）的 terminal 中，Shift+非 ASCII 鍵（例如 Shift+ä → Ä）輸入被吃掉的問題
- Additional fixes: PowerShell 指令驗證、orphaned background processes、voice mode 認證、managed settings、background agent sessions

**核心概念（簡單說）：**
這版更新有三個主軸：**安全性**（sandbox.credentials 讓沙盒環境無法存取機密；org model restrictions 讓管理員可強制全組織用指定模型）、**穩定性**（remote MCP hang、resume 失敗、structured output 無限迴圈等重要修復）、**使用體驗**（fullscreen 滑鼠支援、JetBrains 閃爍修復、WezTerm/Ghostty 特殊字元輸入修復）。

其中 remote MCP tool calls hanging 的修復對日常使用影響最大——如果你有接 GitHub MCP、Figma MCP 等 remote MCP server，過去遇到工具無回應時會卡住等 5 分鐘，這版起改為直接報錯讓你能繼續工作。

**前端工程師實際應用：**
- **跟你工作的關聯：** Remote MCP hang 修復對你有直接影響——如果你的 Claude Code setup 有接 remote MCP server（例如 GitHub MCP、Figma MCP、Linear MCP），更新後遇到 MCP 無回應時不再卡住 5 分鐘，而是立刻拿到錯誤訊息。
- **具體場景：** 如果你在用 WezTerm 或 Ghostty 作為主力 terminal 搭配 Claude Code，更新後在指令裡輸入包含 Shift+非 ASCII 字元（例如德文、法文字元）就不會再消失；如果你用 JetBrains IDE 內建 terminal，閃爍問題也解決了。
- **這週可以嘗試：** 執行 `npm install -g @anthropic-ai/claude-code@latest` 更新到最新版，然後跑 `claude --version` 確認已更新到 2.1.187 或更新版本。
