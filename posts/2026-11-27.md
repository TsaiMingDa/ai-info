**核心概念（簡單說）：**
「reps」是健身用語，指重複次數（repetitions）。這句話（附一段影片）延續他置頂貼文「you have to be bad at it for a while」（任何事都得先爛一陣子）的主題：技能不是靠讀懂原理就會，而是靠大量重複、在每次回饋中微調。放到 AI coding 的脈絡，就是「怎麼跟 agent 協作」本身也是一種需要反覆練習的技能：怎麼拆任務、怎麼寫 prompt、什麼時候該打斷它、怎麼驗收結果，都要練過很多次才會有手感。

**前端工程師實際應用：**
- **跟你工作的關聯：** 很多前端工程師試用 AI agent 幾次、覺得「產出不穩」就放棄，其實常是練習次數不夠。和學 CSS layout 或 React hooks 一樣，跟 agent 合作的直覺需要累積。
- **具體場景：** 每天挑一個小任務（例如把一個 class component 改成 function component、補一組 Vitest 測試、修一個 a11y 警告）交給 Claude Code，做完後花兩分鐘回顧：哪段指示讓它走偏？下一次怎麼說會更好？
- **這週可以嘗試：** 建一個簡單的筆記（或專案裡的 `notes/agent-reps.md`），連續五個工作天每天記一筆「我給 agent 的任務、結果、下次改進點」，週末回頭看有沒有重複出現的問題，把它寫進 `CLAUDE.md` 或做成 skill。
