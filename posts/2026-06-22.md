## Claude Code · Changelog

> ⚠️ 2026-06-21 之後無新版本，以下列出最近一次更新（2026-06-20）作為參考。

**版本號 / 日期：** 2.1.185 / June 20, 2026

**變更項目：**
- The stream-stall hint now reads "Waiting for API response · will retry in …" instead of "No response from API · Retrying in …", and triggers after 20s of silence instead of 10s（串流停頓提示文字更新，觸發時間從 10 秒延長到 20 秒）

**核心概念（簡單說）：**
這次更新只有一個小調整：當 Claude Code 在等待 API 回應時，畫面上的提示訊息變得更友善、更精確。舊版本寫的是「API 沒有回應 · 正在重試」，容易讓人以為出錯了；新版改成「等待 API 回應 · 將在 X 秒後重試」，更清楚表達這是正常的等待狀態。同時把觸發門檻從 10 秒拉長到 20 秒，減少短暫網路延遲就顯示提示的假警報。

**前端工程師實際應用：**
- **跟你工作的關聯：** 使用 Claude Code 跑長時間 agentic 任務（例如跑測試、生成大量程式碼）時，會更清楚知道目前是在等待 API 還是真的卡住了
- **具體場景：** 在 CI 環境或 Remote Control 模式下跑 `claude -p "refactor all components"` 時，若 API 短暫慢速，不會在 10 秒就跳出讓人誤以為失敗的提示
- **這週可以嘗試：** 執行一個稍微長一點的 Claude Code 任務（例如 `claude "explain this codebase"`），觀察新的等待提示文字，確認你的工作流程是否受影響
