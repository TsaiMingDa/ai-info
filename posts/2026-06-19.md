- **具體場景：** 設定一個 `/loop` 或 `/schedule` routine，每次 PR 提出後自動讓 Claude 跑 `eslint --fix`、執行 `vitest`，並把結果 commit 回 branch——不需要開著電腦守著。

## Claude Code · Changelog

**版本號 / 日期：** Week 24 (v2.1.166–v2.1.176) / 2026-06-08–12

**變更項目：**
- `/cd` 指令：在不重建 prompt cache 的情況下，把目前 session 移到不同工作目錄（`/cd ../other-project`）
- Sub-agents 可以生成自己的 sub-agents（背景模式最深 5 層，前台無限）；`claude agents` 顯示完整的 nested tree
- `--safe-mode` 旗標（或 `CLAUDE_CODE_SAFE_MODE`）：以停用所有自訂設定（CLAUDE.md、plugins、skills、hooks、MCP servers）的狀態啟動，用於排錯
- `fallbackModel` 設定：可設定最多三個備援模型，主模型過載時自動切換
- Session 標題現在以對話語言生成
- Cross-session messaging 安全性強化：其他 session 透過 `SendMessage` 傳來的訊息不再享有 user 權限
- `enforceAvailableModels` 受管設定：讓 `availableModels` 白名單也約束預設模型選擇
- 修復 auto mode 在 Fable 5 上因組織未啟用 Opus 4.8 而失敗的問題

**核心概念（簡單說）：**
這週最重要的是 `/cd` 和 nested sub-agents 兩個功能。`/cd` 解決了「開始做 A 專案後才發現需要切到 B 專案」的常見場景，不需要重開 session；nested sub-agents 則讓 Claude 可以組織一個真正的「工作樹」——主 agent 分派任務給子 agent，子 agent 再進一步分派，形成可視化的平行執行結構。`--safe-mode` 則是個救生工具，當你不確定是哪個自訂設定造成問題時，可以先排除所有外部因素。

**前端工程師實際應用：**
- **跟你工作的關聯：** `/cd` 對 monorepo 開發非常實用——你可以在同一個 Claude session 裡來回切換 `packages/web`、`packages/api`、`packages/shared` 等子目錄，不會中斷對話上下文。
- **具體場景：** 在一個 session 裡先 `/cd packages/api` 讓 Claude 修改後端 API，然後 `/cd packages/web` 讓它更新對應的前端 fetch 邏輯，整個流程連貫、不需另開 session。
- **這週可以嘗試：** 如果你的 Claude Code 出現奇怪行為，先試試 `claude --safe-mode` 確認是否是 CLAUDE.md 或某個 plugin 造成的，可以快速縮小問題範圍。

- 修復在網路硬碟和雲端同步資料夾上 Write/Edit 產生 0 bytes 或截斷檔案的問題
- 修復啟動 regression（`~/.aws` 設定或多 MCP 場景下最多 15 秒空白）
- 修復前台 subagent 無限遞迴生成 nested chains 的問題（現在同樣限制 5 層）

**核心概念（簡單說）：**
v2.1.181 主要是體驗優化和 bug 修復。最值得注意的是 `/config key=value` 語法——過去要改設定需要手動編輯 JSON 檔，現在可以直接在對話框輸入，特別適合在 Remote Control 或 script 模式（`-p`）下即時調整行為。串流改進讓長回應的感受更流暢。

**前端工程師實際應用：**
- **跟你工作的關聯：** `/config thinking=false` 這類語法讓你可以在一個 session 裡快速切換模型行為，不需要出去編輯設定檔再重開，在反覆測試不同設定時很省時。
- **具體場景：** 在做需要快速回應的任務時輸入 `/config thinking=false` 關掉 extended thinking 省 token，做需要深度分析時再 `/config thinking=true` 開回來。
- **這週可以嘗試：** 執行 `claude update` 升級到最新版（2.1.181），確認 subagent panel 的閒置自動隱藏是否讓你的多工介面更整潔。
