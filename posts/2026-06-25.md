## Claude Code · Changelog

**版本號 / 日期：** 2.1.191 / June 24, 2026

**變更項目：**
- Added `/rewind` support for resuming a conversation from before `/clear` was run（新增 /rewind：可以回到 /clear 之前的對話狀態重新開始）
- Fixed scroll position jumping to the bottom while reading earlier output during a streaming response（修正串流回應時捲動位置自動跳到底部的問題）
- Fixed background agents resurrecting after being stopped — stopping an agent from the tasks panel is now permanent（修正從 tasks panel 停止 agent 後仍會重新啟動的問題，現在停止即永久停止）
- Fixed `/voice` showing a generic "not available" message when disabled by organization policy — it now explains the restriction（修正 /voice 被組織政策停用時顯示通用錯誤訊息，現在會說明限制原因）
- Fixed `/login` URL opening truncated in Windows Terminal（修正 Windows Terminal 換行時 /login URL 被截斷的問題）
- Fixed Cmd+click on links in fullscreen mode for Ghostty over ssh/tmux（修正 Ghostty over ssh/tmux 全螢幕模式下 Cmd+click 連結無效）
- Fixed claude agents sending builtin slash commands like `/usage` to background sessions as prompt text（修正 background session 中 /usage 等指令被當作一般文字傳送的問題）
- Fixed hooks with comma-separated matchers (e.g. `"Bash,PowerShell"`) silently never firing（修正 hooks 用逗號分隔多個 matcher 時靜默失效的問題）
- Fixed `/permissions` Recently-denied tab: approving a denial now persists on close（修正 /permissions 頁面「近期拒絕」標籤，核准後關閉不再被丟棄）
- Fixed managed settings: `forceRemoteSettingsRefresh` now takes effect via MDM or file policy（修正 MDM/檔案政策設定 forceRemoteSettingsRefresh 不生效的問題）
- Improved sandbox network permission dialog: hosts allowed with "Yes" are now remembered for the rest of the session（改善沙箱網路權限：允許的 host 在整個 session 內都記住，不再每次重新詢問）
- Improved MCP server reliability: capability discovery retries transient network errors with short backoff（改善 MCP server 穩定性：capability discovery 會在短暫網路錯誤時自動重試）
- Improved MCP OAuth: headless environments skip browser popup and go straight to paste-the-URL prompt（改善 MCP OAuth：無頭環境跳過瀏覽器彈窗，直接提示貼上 URL）
- Improved MCP error messages: HTTP 404 errors now show the URL and point to your MCP config（改善 MCP 404 錯誤訊息，顯示 URL 並指向 MCP 設定）
- Improved vim mode prompt-history search (NORMAL `/`) to hint how to reach slash commands（改善 vim 模式歷史搜尋，提示如何使用 slash commands）
- Reduced CPU usage during streaming responses by ~37% by coalescing text updates to 100ms（串流回應期間 CPU 使用量降低約 37%，透過合併 100ms 內的文字更新）
- Reduced long-session memory growth from terminal output cache（減少長時間 session 的終端輸出快取記憶體洩漏）

**核心概念（簡單說）：**
這次 2.1.191 是一次密集的修補 + 優化版本。最值得關注的有三點：（1）新增 `/rewind`，讓你在對話中途執行 /clear 之後還能「後悔」，回到清除前的狀態繼續，大幅降低誤操作的損失；（2）串流回應 CPU 降低 37%，對長時間使用 Claude Code 的人來說體感會明顯改善；（3）hooks 的 comma-separated matcher bug 被修復，之前設定 `"Bash,PowerShell"` 的 hooks 完全不觸發，現在才正常。

**前端工程師實際應用：**
- **跟你工作的關聯：** /rewind 解決了「跑到一半 /clear 之後發現要參考前面對話」的問題；CPU 優化讓長時間 vibe coding session 不再那麼耗能；MCP 穩定性改善也代表整合外部工具（如 Figma、Linear）的連線更可靠
- **具體場景：** 在 Claude Code 裡做大型 refactor 時，中途 /clear 清理 context 後突然需要參考前面討論過的架構決策，現在可以直接 /rewind 回去看，而不是從 terminal scroll 翻找或重新問
- **這週可以嘗試：** 如果你有設定 hooks（例如在 PostToolUse 時自動 lint），而且用了逗號分隔多個 tool matcher，升級到 2.1.191 後確認 hooks 是否現在能正常觸發；同時試試 /rewind，感受一下在長 session 中的實用性
