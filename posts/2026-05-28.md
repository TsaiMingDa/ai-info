## Claude Code · Changelog

**版本號 / 日期：** v2.1.153 / 2026-05-28

**變更項目：**
- **Git LFS Support** — 新增 `skipLfs` 選項給 `github`/`git` plugin marketplace sources，可略過 Git LFS 下載（適合含有大型 binary 資源的專案）
- **npm Update Notifications** — 當 npm global install 無法自動更新時，Claude Code 顯示一次性提示；`/doctor` 也會列出修復步驟
- **Terminal Environment Variables** — Status line 指令現在可接收 `COLUMNS` 和 `LINES` 環境變數，確保輸出尺寸隨終端視窗正確縮放
- **Agent Improvements** — `/claude agents` 的 autocomplete 現在建議 native slash commands 和 bundled skills；PR 欄位顯示 `PR #N`（單一）或 `N PRs`（多個）
- **Background Agents** — 在 Claude 正在回應時執行 `/bg`，可把當前 response 繼續移到背景 session 執行，不打斷進行中的工作
- **Model Selection** — `/model` 現在把選擇存為新 session 的預設；按 `s` 只更改當前 session 的 model
- **Bug Fixes** — 修復 MCP servers 沒有 optional GET SSE stream 時的重連迴圈、custom API gateway 收到 user's Anthropic OAuth credential 而非 gateway token 的問題、subagent MCP servers 忽略 `--strict-mcp-config` 等設定的問題、Windows PowerShell 假安裝完成訊息、resuming sessions 時記憶體過高問題，以及多個 background session 和 UI 渲染問題

**核心概念（簡單說）：**
v2.1.153 是 Opus 4.8 發布同天推出的 Claude Code 小版本更新，核心是穩定性和使用體驗精修。最值得注意的有兩點：一是 `/model` 的行為調整——現在設定後自動記住為新 session 的預設，不用每次手動選；二是 background agents 的 `/bg` 更靈活——即使 Claude 還在回應中途，也可以把它推進背景繼續跑，讓你立刻開新 session 處理別的事。

**前端工程師實際應用：**
- **跟你工作的關聯：** `/model` 記住預設值這件事讓你可以「設定一次、永遠生效」——搭配今天 Opus 4.8 上線，可以直接把新模型設為預設，之後每個 session 都自動用最新版本，不用再想這件事。
- **具體場景：** 你同時在處理兩個任務——一個 session 在進行長時間的 TypeScript 型別遷移，另一個要開始新功能的規格討論。用 `/bg` 把遷移任務推進背景繼續跑，然後開新 session 處理規格，兩個任務並行，互不干擾。
- **這週可以嘗試：** 更新到 v2.1.153（`npm update -g @anthropic-ai/claude-code`），用 `/model` 把 Opus 4.8 設為預設（選完按 Enter 不是按 `s`），然後執行 `/doctor` 確認環境設定，看看有沒有需要修復的問題。
