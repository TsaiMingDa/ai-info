> We've been putting a lot of effort into making Claude Code more responsive & reliable.
>

>
> First for our new full-screen renderer (which should get rid of bugs like screen flickering), we've made a number of fixes for different environments and terminals. You can turn it with the command: /tui feedback. We're working on making it the default in Claude Code soon.
>
> We've greatly improved the responsiveness of Claude while working. Thinking & tool calls are streamed and we've fixed a number of bugs that might have made it look like Claude was hanging while it was just thinking for a long period of time.
>
> Fewer mysterious error messages. We've chased down several root causes of errors like "tool result doesn't match tool use", as well as made other error messages more readable so you can tell what's happening.
>
> Compaction now shows its progress, and you should no longer run into "prompt too long" bugs which prevent you from compacting. We're rolling out more changes to improve the speed at which Claude compacts.
>
> MCP has gotten a lot more reliable. We've shipped a batch of fixes for connection failures, OAuth flows, and proxy rate-limiting.
>
> Self-healing sessions. Images or media files that were too big or unreadable used to brick your session until you restarted. Claude Code now detects it and recovers automatically.
>
> It's now easier than ever to send feedback. When you hit /feedback, you can now just send over the last day or week of sessions instead of having to remember which session had the bug in it.
>
> And we're still working! Please let us know if there are any bugs that are impacting your experience, and keep the feedback rolling in with /feedback. We monitor feedback daily. More improvements coming in the next days / weeks.

## Claude Code · Changelog

**版本號 / 日期：** 2.1.153 / May 28, 2026

**變更項目：**
- Added `skipLfs` option to github/git plugin marketplace sources to skip Git LFS downloads during clone and update（github/git plugin marketplace 來源新增 `skipLfs` 選項，可跳過 Git LFS 下載）
- Claude Code now shows a one-time notice when your npm global install can't auto-update; `/doctor` lists the fixes（npm 全域安裝無法自動更新時會顯示一次性提示，`/doctor` 會列出修復方式）
- Status line commands now receive `COLUMNS` and `LINES` environment variables so scripts can size output to the terminal width（status line 指令現在會接收 `COLUMNS` 和 `LINES` 環境變數，讓腳本可以根據終端寬度調整輸出）
- `claude agents`: autocomplete in the dispatch input now suggests native slash commands and bundled skills, not just project skills（`claude agents` 的 dispatch 輸入自動完成現在會建議原生 slash commands 和 bundled skills）
- `claude agents`: PR column now shows `PR #N` for a single PR or `N PRs` for multiple（PR 欄位現在顯示 `PR #N` 或 `N PRs`）
- `claude doctor` now shows the result of your last update attempt（`claude doctor` 現在會顯示上次更新嘗試的結果）
- Combined the separate "needs authentication" startup notifications for MCP servers and connectors into a single message（合併了 MCP server 和 connector 的「需要驗證」啟動通知為一則訊息）
- macOS: background agents now appear as "Claude Code" in Privacy & Security and keep their permission grants across upgrades（macOS 上背景 agent 在「隱私與安全性」中顯示為「Claude Code」，升級後權限保留）
- Fixed stateful MCP servers without the optional GET SSE stream reconnect-looping on `tools/list`（修復了沒有 GET SSE stream 的 stateful MCP server 在 `tools/list` 上反覆重連的問題）

**核心概念（簡單說）：**
2.1.153 是一個偏向「打磨體驗」的更新。最實用的改進包括：`claude agents` 的自動完成變得更聰明（不只是 project skills，還包含原生 slash commands）；npm 全域安裝的自動更新問題現在有明確提示和修復指引；status line 腳本可以感知終端寬度了。macOS 使用者會注意到背景 agent 在系統隱私設定中有更好的辨識度，升級後不需要重新授權。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你用 `claude agents` 管理多個平行任務（例如同時跑 lint、test、build），自動完成的改善讓你操作更快；status line 的終端寬度感知讓自訂腳本在不同視窗大小下都能正確顯示
- **具體場景：** 在 macOS 上使用 Claude Code 背景 agent 自動跑 CI 任務時，升級後不需要重新到「隱私與安全性」授權，減少中斷
- **這週可以嘗試：** 更新到 2.1.153（`npm update -g @anthropic-ai/claude-code`），然後在 `claude agents` 的 dispatch 輸入框試試自動完成，體驗新的 slash command 建議

**版本號 / 日期：** 2.1.152 / May 27, 2026

**變更項目：**
- `/code-review --fix` now applies review findings to your working tree after the review, surfacing reuse, simplification, and efficiency suggestions; `/simplify` now invokes `/code-review --fix`（`/code-review --fix` 現在會將 review 結果直接套用到你的工作目錄；`/simplify` 改為呼叫 `/code-review --fix`）
- Skills and slash commands can now set `disallowed-tools` in frontmatter to remove tools from the model while the skill is active（Skills 和 slash commands 可在 frontmatter 設定 `disallowed-tools`，在技能啟用期間移除模型可用的工具）
- Added `/reload-skills` command to re-scan skill directories without restarting the session（新增 `/reload-skills` 指令，不需重啟 session 即可重新掃描技能目錄）
- SessionStart hooks can now return `reloadSkills: true` to re-scan skill directories（SessionStart hook 可回傳 `reloadSkills: true` 來重新掃描技能目錄）
- SessionStart hooks can now set the session title via `hookSpecificOutput.sessionTitle` on startup and resume（SessionStart hook 可透過 `hookSpecificOutput.sessionTitle` 設定 session 標題）
- Added a `MessageDisplay` hook event that lets hooks transform or hide assistant message text as it is displayed（新增 `MessageDisplay` hook 事件，讓 hook 可以在顯示時轉換或隱藏 assistant 訊息）
- Added `pluginSuggestionMarketplaces` managed setting: admins can allowlist org marketplaces whose plugins may be suggested via context-aware tips（新增 `pluginSuggestionMarketplaces` 管理設定，管理員可設定允許建議的 marketplace）
- `claude plugin marketplace remove` now accepts `--scope user|project|local` for symmetry with `marketplace add`, `install`, and `uninstall`（`claude plugin marketplace remove` 現在接受 `--scope` 參數）
- The `/usage` breakdown now includes large session files; files are scanned with a streaming read so memory usage stays flat（`/usage` 現在包含大型 session 檔案的明細，使用串流讀取避免記憶體飆升）
- Thinking summaries in the collapsed group now stay readable for at least 3 seconds, render as markdown, and cap at 10 lines（摺疊群組中的 thinking 摘要至少保持可讀 3 秒、以 markdown 渲染、最多 10 行）
- In fullscreen mode, the "Thinking for Ns" indicator now counts up live while the model is thinking（全螢幕模式的「Thinking for Ns」指示器現在會即時往上計數）
- Added the session entrypoint as an OpenTelemetry metric attribute（新增 session 進入點作為 OpenTelemetry metric 屬性）
- Fixed terminal styling degrading in very long sessions by recycling the renderer's style pool（修復長時間 session 中終端樣式劣化的問題）
- Fixed the sandbox-enabled warning not appearing in condensed startup mode（修復 sandbox 啟用警告在精簡啟動模式不顯示的問題）
- Fixed markdown table cell borders inheriting the color of inline code（修復 markdown 表格邊框繼承 inline code 顏色的問題）
- Fixed plugin MCP servers with the same command but different environment variables being incorrectly deduplicated（修復相同指令但不同環境變數的 plugin MCP server 被錯誤去重的問題）
- Fixed `/doctor` reporting "marketplace not found" for stale `enabledPlugins` entries（修復 `/doctor` 對已移除的 marketplace 報錯的問題）
- Fixed plugins that track a git branch silently no longer receiving updates after the plugin registry was rebuilt（修復追蹤 git branch 的 plugin 在 registry 重建後不再收到更新的問題）
- Fixed remote MCP servers failing to connect in Claude Code Remote sessions when the egress proxy is enabled（修復啟用 egress proxy 時遠端 MCP server 無法連接的問題）
- Fixed the effort-change confirmation dialog appearing when the conversation has no messages（修復在無訊息的對話中切換 effort level 時出現確認對話框的問題）

**核心概念（簡單說）：**
2.1.152 是一個「重量級」更新。最大亮點是 `/code-review --fix`：不只告訴你哪裡有問題，還直接幫你改好——這讓 code review 從「唯讀」變成「可執行」。Skill 系統也大幅增強：`disallowed-tools` 讓你精細控制技能啟用時 model 能用哪些工具、`/reload-skills` 不用重啟就能載入新技能、`MessageDisplay` hook 讓你能在顯示層攔截和修改 AI 的輸出。這些改動加在一起，代表 Claude Code 的擴展性（extensibility）正在快速成熟。

**前端工程師實際應用：**
- **跟你工作的關聯：** `/code-review --fix` 直接改變你的 code review 工作流——以前用 Claude Code review 完還要手動改，現在它直接幫你修好；`/reload-skills` 讓你在開發自訂 skill 時可以快速迭代測試
- **具體場景：** 在提交 PR 前，跑 `/code-review --fix` 讓 Claude 自動找出可以簡化、重用或提升效率的地方，直接套用修改，然後你只需要 review 這些變更是否合理
- **這週可以嘗試：** 更新到 2.1.152+，在你目前的專案中跑一次 `/code-review --fix`（或 `/simplify`），看看 Claude 能找出多少可改善的地方；如果你在開發自訂 skill，試試 `/reload-skills` 的即時重載功能
