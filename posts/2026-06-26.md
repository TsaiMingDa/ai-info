## Claude Code · Changelog

**版本號 / 日期：** 2.1.193 / June 25, 2026

**變更項目：**
- Added `autoMode.classifyAllShell` setting — 讓所有 Bash/PowerShell 指令都走 auto-mode 分類器審查，不只是被辨識為「任意程式碼執行」的指令才審
- Added auto-mode denial reasons to the transcript, denial toast, and `/permissions` recent denials — auto mode 拒絕執行時，現在會在記錄、提示和 `/permissions` 頁面顯示拒絕原因
- Added `claude_code.assistant_response` OpenTelemetry log event — 包含 model 回應文字，預設不記錄（需設 `OTEL_LOG_ASSISTANT_RESPONSES=1` 啟用）；若未設此變數，則跟隨 `OTEL_LOG_USER_PROMPTS` 設定
- Added live file path autocomplete in bash mode (`!`) — 在 bash 模式下輸入 `!` 時，現在支援即時路徑自動補全
- Added startup notice when MCP servers need authentication — 啟動時若 MCP server 需要認證，會主動顯示提示並指向 `/mcp`
- Added automatic memory-pressure reaping for idle background shell commands — 閒置的背景 shell 自動回收記憶體（可用 `CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP=1` 關閉）
- Fixed `/model` and client-data-gated UI showing stale/empty state after `/login` — 修正登入後 `/model` 顯示舊資料的問題
- Fixed backgrounding (`←←`) spuriously cancelling when all running tasks carry over — 修正按 `←←` 背景化時，誤報「N background tasks would be abandoned」的問題
- Fixed pinned background agents being re-prompted after every auto-update — 修正 pinned 背景 agent 在每次自動更新後重複提示「Continue from where you left off」的問題
- Fixed backgrounding main turn spawning phantom "general-purpose (resumed)" subagent — 修正把主對話背景化後，會多生出一個幽靈 subagent 重跑對話的 bug
- Fixed agent panel hiding sibling agents when viewing a subagent — 修正查看 subagent 時，其他同層 agent 被隱藏的問題
- Improved background agents: launch result no longer instructs Claude to "end your response" — 背景 agent 啟動後，Claude 現在可以繼續在主對話處理其他任務
- Improved MCP `headersHelper` auth: auto re-runs and reconnects on 401/403 — MCP auth helper 在收到 401/403 時會自動重新執行並重連
- Improved plugin auto-rename: marketplace rename maps now followed automatically — plugin 更名時會自動更新 settings，不需要手動改
- Improved `/add-dir` message when directory is already a working directory — 改善提示訊息

**核心概念（簡單說）：**
這次 2.1.193 是一個以「穩定性和可觀測性」為核心的更新。在 auto mode 方面，新增了更細緻的分類器控制和拒絕原因記錄，讓安全策略更透明；在 background agent 方面，修了多個讓背景任務不穩定的 bug，同時改善了 agent 啟動後的行為（不再強迫 Claude 中斷主對話）。OpenTelemetry 整合的強化則是針對企業部署，讓 ops 團隊能更完整地審計 model 的回應內容。

**前端工程師實際應用：**
- **跟你工作的關聯：** bash mode 的路徑自動補全（`!`）是日常操作頻率很高的改善，讓你在 Claude Code 內操作檔案系統時更順暢；background agent bug 修復讓多工作業更可靠
- **具體場景：** 在 bash mode 輸入 `! cat src/` 時，現在可以即時看到路徑補全選項，不需要離開 Claude Code 去 terminal 確認路徑再回來貼上；同時跑多個 background agent 處理不同 feature 分支時，不再會有幽靈 agent 亂入
- **這週可以嘗試：** 升級到 2.1.193（`npm update -g @anthropic-ai/claude-code`），試試在 bash mode 下用 `!` 指令的路徑自動補全，感受一下補全速度和準確度
