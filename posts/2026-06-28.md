## Claude Code · Changelog

**版本號 / 日期：** 2.1.195 / June 26, 2026（最近一次更新，本日無新版本）

**變更項目：**
- Added `CLAUDE_CODE_DISABLE_MOUSE_CLICKS`：新環境變數，可在 fullscreen 模式下停用滑鼠點擊／拖拽／hover，但保留滾輪捲動功能
- Fixed hook matchers with hyphenated identifiers（如 `code-reviewer`、`mcp__brave-search`）意外做 substring-matching 的問題，現在改為完全相符（exact-match）；若要匹配所有帶連字號 MCP server 的工具，請用 `mcp__brave-search__.*`
- Fixed voice dictation on macOS 在長時間 session 後因預設輸入裝置變更而捕捉到靜音的問題
- Fixed voice dictation auto-submit 對無空格語言（日文、中文、泰文）永遠不觸發的問題
- Fixed 僅透過 project `.claude/settings.json` 啟用的 external plugin 在每次 loader path 都需要重新確認安裝同意的問題
- Fixed `/plugin` Enable/Disable 在 plugin 的 `plugin.json` name 與 marketplace entry name 不同時無法運作
- Fixed background jobs 在 `claude agents` 消失或被較新版 Claude Code 寫入時遺失資料的問題
- Fixed 重新開啟已崩潰 background task 時最多需等 5 秒才出現畫面（現在改為立即顯示重啟狀態）
- Fixed background agent daemon 在 control socket 啟動失敗時無法連線，阻擋重啟的問題
- Improved voice mode on Linux：現在能區分「沒有麥克風」與「SoX 未安裝」（SoX 存在但無音訊捕捉裝置時的情況）
- Improved `claude agents` 已完成清單現在會填滿可用垂直空間；終端機較短時 header 會自動縮小，讓 live sessions 保持可見
- Improved Remote session 啟動時新增 provisioning checklist，顯示容器啟動進度

**核心概念（簡單說）：**
本次 2.1.195 是一個修 bug 為主的版本，聚焦在三個面向：(1) hook matcher 的 hyphen 問題——以前 `mcp__brave-search` 這類含連字號的 matcher 會意外匹配到含有這個字串的其他工具，現在改為嚴格相符；(2) voice dictation 的穩定性，特別是 macOS 長時間 session 與中日文無法觸發的問題；(3) background agents 的可靠性，包含崩潰後重啟速度和 daemon 連線問題。

**前端工程師實際應用：**
- **跟你工作的關聯：** Hook matcher 的修正直接影響所有在 `.claude/settings.json` 裡設定過 hook 規則的開發者；如果你有針對特定 MCP 工具設定 hook，升級後行為會更精確可預期
- **具體場景：** 假設你有一個 hook 要攔截 `mcp__brave-search__search` 的呼叫，舊版本可能會意外匹配到名字裡包含 `brave-search` 的其他工具；升級到 2.1.195 後，hook 只會精確匹配，若要匹配同一 MCP server 的所有工具，改用 `mcp__brave-search__.*` 正規表達式
- **這週可以嘗試：** 執行 `claude --version` 確認版本，若尚未更新到 2.1.195 則執行 `npm install -g @anthropic-ai/claude-code` 升級；同時檢查 `.claude/settings.json` 裡的 hook matchers，確認帶連字號的識別符是否需要改為 `.*` 通配模式
