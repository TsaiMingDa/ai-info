> More than 25,000 nonprofits now use Claude. Most are small, local teams.

**繁中改寫：**
目前已有超過 25,000 個非營利組織在使用 Claude，其中多數是小型、在地的團隊。

我們正在擴充 Claude for Nonprofits：和大約 30 個非營利組織一起打造了一個 plugin，加入募款、行銷、招募相關的 skills，而且這些 skills 會根據每個團隊自己的背景脈絡與 AI 使用政策來運作。詳情：https://claude.com/resources/articles/expanding-claude-for-nonprofits

**核心概念（簡單說）：**
重點不在「非營利」，而在交付方式：Anthropic 越來越常把垂直領域的能力包成 **plugin + skills** 發佈，而不是另外做一個新產品。plugin 是一個可安裝的套件，裡面打包多個 skill（一份份寫好的工作說明書 + 範本 + 腳本），Claude 在需要時才載入對應的 skill。「grounded in each team's context and AI policy」代表 skill 不是寫死的萬用 prompt，而是會讀取該團隊自己提供的資料（組織使命、品牌語氣、內部 AI 規範）再產出內容。

用前端的比喻：這就像一個 design system 套件——元件（skill）是共用的，但透過 theme token（團隊 context）讓每家用起來長得不一樣。而「和 30 個組織共同開發」則是典型的 design partner 模式，先用真實使用者校準 skill 的行為。

**前端工程師實際應用：**
- **跟你工作的關聯：** 同樣的 plugin / skills 機制在 Claude Code 也能用。你的團隊可以把「元件命名規範、a11y checklist、PR 描述格式」包成 skill，讓每個人的 Claude 都遵守同一套前端規則。
- **具體場景：** 團隊常抱怨新同事寫的 React 元件不符合內部規範；你可以在 repo 加一個 `.claude/skills/component-conventions/SKILL.md`，寫清楚資料夾結構、props 命名、Storybook story 要求，並在 skill 中引用團隊既有的 `CONTRIBUTING.md` 當作 context，Claude 產生元件時就會自動套用。
- **這週可以嘗試：** 挑一個你每週都會重複做的前端雜事（例如寫 Storybook story 或補 Playwright 測試），花 30 分鐘把步驟寫成一個 SKILL.md，下次直接請 Claude Code 依該 skill 執行，比較產出品質與手寫 prompt 的差異。

## Claude Code · Changelog

**版本號 / 日期：** 2.1.311 / October 26, 2026

**變更項目：**
- Added `--hold-idle-file` and `--max-hold-min` to self-hosted-runner, to keep an idle session while your host reports processes it left running（self-hosted runner 新增參數，主機回報仍有殘留程序時可讓閒置 session 保持存活）
- Added a tip for the Explanatory output style, shown when you ask Claude for explanations（請 Claude 解釋時，會提示可改用 Explanatory 輸出風格）
- [VSCode] Added syntax coloring to code blocks in Claude's replies, in light, dark and high contrast dark themes（VS Code 擴充的回覆程式碼區塊支援語法上色）
- [VSCode] Added a "Running UserPromptSubmit hooks" spinner status and screen reader announcement for slow UserPromptSubmit hooks（慢的 UserPromptSubmit hook 會顯示進度與螢幕閱讀器提示）
- [Claude Tag] Added a Skills view to Claude Tag analytics showing how often Claude runs each attached skill in Slack channels and which go unused（Claude Tag 分析頁新增 skill 使用次數檢視）
- Changed ultrathink in the interactive terminal to run its turn at xhigh effort on Opus 5.5, Sonnet 5.5, Haiku 5.5 and Fable 5.1 through Anthropic's API; typed while Claude is working, it raises the rest of that turn（在互動終端輸入 ultrathink 會把該回合提升到 xhigh effort；在 Claude 執行中輸入也能即時拉高剩餘回合）
- Changed the ultrathink rainbow to appear only where the keyword can raise effort, and not when the word is quoted or part of a file path（ultrathink 彩虹效果只在真的會生效時顯示）
- Changed Ctrl+D in agent view to match the prompt: on an empty input, pressing it twice exits（agent view 中空輸入按兩次 Ctrl+D 離開）
- Changed `--output-format json` and `stream-json` output to write DEL, C1 control and Unicode format characters inside strings as `\uXXXX` escapes; parsed values are unchanged（JSON 輸出會跳脫控制字元，解析後的值不變）
- Changed model names and IDs to drop the `[1m]` suffix and its label on models where the suffix has no effect; the suffix is still accepted（無作用的 `[1m]` 後綴不再顯示，但仍可接受）
- Changed startup warnings about permission rules in settings files to show once per user until the rule changes（設定檔權限規則警告每位使用者只顯示一次）
- Changed `/code-review` to tell Claude to put the effort level first and use max only when asked（`/code-review` 指示 Claude 先決定 effort，只有被要求才用 max）
- Changed `DISABLE_COMPACT` in settings files and in a mod's `$.env.set` so they can only turn compaction off, not back on（`DISABLE_COMPACT` 只能用來關閉 compaction）
- Changed Claude Code on Bedrock, Mantle, Vertex, and Foundry to load model settings from a signed file on downloads.claude.ai; set `CLAUDE_CODE_MODEL_CATALOG=off` to turn this off（雲端供應商版本改從簽章檔載入模型設定，可用環境變數關閉）
- Changed sessions that set `CLAUDE_CODE_SYNC_SKILLS` with feature-flag fetching off to reuse a claude.ai skills list up to 10 minutes old that another session on the machine fetched（同機器多個 session 共用 10 分鐘內的 skills 清單快取）
- Changed clicks on scrollbar arrows and bars in fullscreen lists to act when the mouse button is released（全螢幕列表的捲軸點擊改在放開滑鼠時才觸發）
- Changed `claude purge` to say it deletes data only on this computer, not anything stored by Anthropic（`claude purge` 明確說明只刪除本機資料）
- [VSCode] Changed the extension to start Claude Code sessions with `DISABLE_TELEMETRY` set while VS Code's telemetry setting is off（VS Code 關閉 telemetry 時，Claude Code session 也一併不送使用指標）
- [VSCode] Changed the session list side bar to load Web sessions when the Web tab is first opened, not at startup（Web sessions 改為延遲載入）
- [Claude Tag] Changed Claude Tag admin settings to show a lock instead of # for private Slack channels that your own Slack account can see（私人頻道以鎖頭圖示顯示）
- 另有 16 項 improvements 與 56 項 bug fixes（頁面預設收合，未逐條列出）

**核心概念（簡單說）：**
這版的主軸是「讓推理強度（effort）更可控」與「VS Code 體驗打磨」。`ultrathink` 從單純的關鍵字變成明確映射到 `xhigh` effort，而且可以在 Claude 工作到一半時輸入、即時拉高剩下的推理預算——類似在跑到一半的 build 中途切成 production 模式。`/code-review` 也改成先決定 effort、不預設用最貴的 max，避免無謂消耗用量。

另外有不少「機器可讀輸出」與隱私相關的細節：`stream-json` 會跳脫控制字元，讓下游 parser 不會被奇怪字元弄壞；VS Code 尊重編輯器本身的 telemetry 設定；`claude purge` 講清楚只刪本機資料。整體偏向穩定性與可預期性的版本。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你在 VS Code 裡用 Claude Code，回覆中的 TSX / CSS 程式碼區塊終於有語法上色，閱讀 diff 與範例程式碼更輕鬆；有寫 UserPromptSubmit hook（例如自動注入 lint 規則）的人也能看到 hook 執行進度。
- **具體場景：** 你請 Claude 重構一個複雜的 React form（混合 react-hook-form 與 zod schema），看它推理到一半發現方向偏了，可以直接在執行中輸入 `ultrathink` 把剩下回合拉到 xhigh，而不必中斷重來；若你用 `claude -p --output-format stream-json` 串 CI 腳本，也不用再自己處理控制字元造成的 JSON parse 錯誤。
- **這週可以嘗試：** 執行 `claude update` 升到 2.1.311，接著在下一個中等難度的前端任務（例如把一個 class component 改成 hooks）中途輸入 `ultrathink`，觀察回覆品質與耗時的差異，再決定哪類任務值得常態使用。
