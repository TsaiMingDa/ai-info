## Claude Code · Changelog

**版本號 / 日期：** 2.1.316 / October 31, 2026（自上次 digest 後無新版本，以下為最近一次更新；主要條目已收錄於 2026-10-31 digest，這裡列出當時未收錄的項目）

**變更項目：**
- Changed auto mode so that an `autoMode.allow` list without `"$defaults"` no longer removes the built-in rule on scheduled-task prompts — 自訂 `autoMode.allow` 清單沒有包含 `"$defaults"` 時，不會再移除 scheduled-task prompt 的內建規則。
- [Cloud sessions] Changed network secrets so Enterprise members can add and delete them on their own cloud environments, instead of only viewing them — Enterprise 成員可以在自己的雲端環境新增、刪除 network secrets，不再只能檢視。
- [Claude Tag] Changed a Slack channel's Respond automatically switch to a "How Claude participates" choice on the channel's Configure page and in Claude Tag admin settings — Slack 頻道的 Respond automatically 開關，改為頻道 Configure 頁面與 Claude Tag 管理設定中的「How Claude participates」選項。
- Improved `/code-review` started from the Code tab in Claude Desktop or on the web: cloud and `claude remote-control` sessions now show the findings card, not a plain-text list — 從 Claude Desktop 的 Code 分頁或網頁啟動 `/code-review` 時，cloud 與 `claude remote-control` session 會顯示 findings 卡片，不再是純文字清單。
- Improved SSL certificate errors to name the likely causes, among them a server that leaves out an intermediate certificate, and the fix for each — SSL 憑證錯誤訊息會指出可能原因（例如伺服器漏掉中繼憑證）和對應的解法。
- Fixed shell commands being left running on macOS and Linux when Claude Code exits by itself — 修正 macOS、Linux 上 Claude Code 自行結束時，shell 指令仍留在背景執行的問題。
- Fixed prompts containing invisible characters needing a second Enter to send — 修正 prompt 含不可見字元時要按第二次 Enter 才送出的問題；一般 prompt 現在按一次就會清理後送出，指令則仍會等待檢視。
- Windows: Fixed the Bash tool losing your aliases and functions in Git Bash when the rc file sets `errexit` and `pipefail` and only winpty aliases, or none, are defined — 修正 Windows 的 Git Bash 在特定 rc 設定下，Bash tool 遺失 alias 和 function 的問題。
- [VSCode] Fixed the missing Effort slider, Ultracode switch and model name when the model setting has the `[1m]` tag, such as `opus[1m]` — 修正 VS Code 中 model 設定帶 `[1m]` 標籤時，Effort slider、Ultracode 開關和 model 名稱消失的問題。
- 此版另有其他項目（共 5 項 improvements 與 34 項 bug fixes），本 digest 未逐條收錄；完整內容見 https://code.claude.com/docs/en/changelog

**核心概念（簡單說）：**
今天沒有新版本。以上幾項都是昨天沒列到的細節，主軸是減少日常使用時的小摩擦：prompt 裡夾帶不可見字元（常見於從網頁或文件複製的文字）時，不必再按第二次 Enter；SSL 錯誤訊息會直接指出可能原因；Claude Code 自行結束時也不會再留下還在執行的 shell 指令。

其中最值得留意的是 shell 指令殘留的修正。如果 Claude Code 因憑證被拒等原因自行結束，先前由它啟動的指令可能繼續在背景執行，例如 dev server 持續佔用 port。這個修正處理的就是這類殘留程序，不過它只涵蓋 macOS 和 Linux。

**前端工程師實際應用：**
- **跟你工作的關聯：** 前端開發常用 Claude Code 跑 dev server、watcher 和測試。如果曾遇到 port 莫名被佔用，或公司內網的 SSL 錯誤難以判斷原因，這版的修正和錯誤訊息都會有幫助。
- **具體場景：** 在公司 proxy 或私有 CA 環境下啟動 Claude Code 時，如果遇到憑證錯誤，可以先看訊息是否指向伺服器漏掉中繼憑證，再把具體原因交給 IT 處理，不必自己從頭猜。
- **這週可以嘗試：** 執行 `claude --version` 確認已更新到 2.1.316。如果你在 VS Code 使用 `opus[1m]` 這類 model 設定，也順便確認 Effort slider 和 model 名稱都正常顯示。
