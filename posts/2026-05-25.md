**版本號 / 日期：** 2.1.149 / May 22, 2026

**變更項目：**
- `/usage` 新增分類明細：按 skills、subagents、plugins、各 MCP server 分別顯示用量佔比（繁中：`/usage` 現在能告訴你哪個功能在吃你的 token 配額）
- `/diff` 詳細檢視支援鍵盤捲動（方向鍵、`j`/`k`、`PgUp`/`PgDn`、`Space`、`Home`/`End`）
- Markdown 輸出現在正確渲染 GFM task list checkboxes（`- [ ] todo` / `- [x] done`）而非純 bullet
- Enterprise：新增 `allowAllClaudeAiMcps` managed setting，可讓 claude.ai 雲端 MCP connectors 與 `managed-mcp.json` 並存載入
- **安全修復**：修正 PowerShell 中 `cd..`、`cd\`、`cd~`、`X:` 等內建 cd 函式可繞過 permission sandbox 變更工作目錄的問題
- **安全修復**：修正 git worktree 沙盒寫入白名單過寬，誤將整個主 repo 根目錄都納入（應只允許 `.git` 目錄）
- **安全修復**：修正 PowerShell prefix/wildcard allow rules（如 `PowerShell(dotnet.exe build *)`）無法預先核准原生執行檔的問題
- 修正 `find` 指令在 macOS 大型目錄下耗盡 vnode table 導致系統崩潰
- 修正 managed-settings 確認對話框在啟動時接受後讓終端機凍結
- 修正 `/ultraplan` 及 remote session 在沒有實際變更時拋出 "Could not capture uncommitted changes" 錯誤
- 修正 thinking spinner 在多次 tool call 間持續顯示琥珀色
- 修正 slash command argument hint 溢出輸入框時截斷尾端字元
- 修正 Tab-complete skill 後 argument hint 未出現的問題
- 修正 status bar 顯示基礎 `/effort` 設定而非 skill/agent frontmatter 套用的 effort 等級
- 修正 `Ctrl+O` transcript 視圖在開啟瞬間凍結而非持續追蹤最新訊息
- 修正編輯已召回的歷史 prompt 後用方向鍵繼續瀏覽時遺失編輯內容
- 修正 `/config` 退出摘要在切換無關設定時誤報 auto-compact 和 theme 有異動
- 改進 `/feedback` 回報內容，現在包含 context compaction 前的對話記錄，方便除錯長對話中的問題

**核心概念（簡單說）：**
2.1.149 是一個以**安全性修復**和**使用體驗打磨**為主軸的版本。最值得關注的是三個 PowerShell permission sandbox 漏洞的修復——這些漏洞讓惡意 agent 可以透過 `cd..` 等內建指令悄悄離開授權的工作目錄，或讓 git worktree 的沙盒保護形同虛設。對一般用戶而言，`/usage` 的分類明細是本版最實用的新功能：當你的 Claude Code 用量快到上限時，可以立刻知道是哪個 skill 或 MCP server 是用量大戶。

**前端工程師實際應用：**
- **跟你工作的關聯：** `/usage` 分類明細直接影響你管理 token 配額的方式——以前只能看總用量，現在可以看出 skills 和 subagents 各佔多少，幫助你決定要精簡哪個工作流程
- **具體場景：** 在跑完一個複雜的 multi-agent PR review 流程後，輸入 `/usage`，看看是 Plan subagent 還是某個 MCP server（例如 GitHub MCP）消耗最多，然後有針對性地調整用法或 effort 等級
- **這週可以嘗試：** 跑你平常最重的 Claude Code 任務後，馬上輸入 `/usage` 截圖記錄，建立你的 token 消費基線，以便未來對比優化效果
