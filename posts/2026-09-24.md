**繁中改寫：**
Anthropic 成立了新的生命科學研究團隊與實驗室，專注於用 Claude 做基礎生物學研究：在 DNA 資料集中找出尚未被描述的蛋白質家族、大規模產生假說，再到實驗室驗證。這篇文章公布早期成果：Claude 在科學家只給出高層次方向的情況下，自主發現了一個新的酵素系統，它旁邊伴隨著一串 DNA 重複序列，結構很像 CRISPR。

研究團隊只寫了一個初始 prompt，請 Claude 在龐大的 DNA 序列資料庫中尋找有趣的反轉錄酶（reverse transcriptase，RT）新案例，其餘都由 Claude agents 自行判斷。約 950 個 agent 花了 21 小時、用掉 2.1 億 token，蒐集超過 20 萬個 RT、挑出 3,500 個候選系統，再收斂成 20 個最值得深究的候選並寫成人類可讀的報告——這種分析對專家來說通常要花數週到數月。其中一個 agent 在看原始 DNA 序列時發現了一段肉眼可見的串聯重複序列，接著像人類科學家一樣計算重複數、量測間距、比對已知系統、查文獻，確認是新系統後才提交報告給人類審閱。這個系統被命名為 ART（array-associated reverse transcriptases），主要存在於噬菌體中，其功能目前仍在研究。CRISPR 先驅、MIT 教授張鋒（Feng Zhang）看過預印本後表示，這是 AI agent 能對生物學發現做出貢獻的精彩案例。

**核心概念（簡單說）：**
這篇的技術重點不是生物學本身，而是「大規模平行 agent 做開放式探索」的架構：先讓 Claude 讀文獻並用公開資料重現既有結果來驗證自己的方法，接著大量平行搜尋、為每個候選寫報告，再由 Claude 自己批判性地審查、淘汰大部分候選，最後才交給人類與實驗室。這是一個「生成 → 自我審查 → 人類把關」的漏斗。

另一個有意思的觀察是：因為 Claude 產出假說的速度太快，「假說本身」變成了研究對象——團隊分析哪些提案被人類判定值得測試、哪些被擱置，再把這些判斷回饋進給 Claude 的指示裡，讓它學會模仿研究團隊的「科學品味」。這個模式可以類比到任何需要從大量候選中挑出好點子的領域。

**前端工程師實際應用：**
- **跟你工作的關聯：** 「平行 agent 掃描 → 各自寫報告 → 自我審查淘汰 → 人類只看少數精選」這個漏斗，完全可以套用到大型程式碼庫的審查工作，例如找效能瓶頸、無障礙問題或技術債。
- **具體場景：** 你們的前端 monorepo 有上百個元件，可以讓 Claude Code 用 subagents 平行掃描每個 package，各自回報疑似的 a11y 問題或不必要 re-render，再請主 agent 批判性地複查、刪除誤報，最後只給你前 10 個最值得修的項目與證據。
- **這週可以嘗試：** 寫一個 prompt 讓 Claude 對你的 `src/components` 做一次「候選 → 自我審查」兩段式的程式碼稽核（第一輪盡量多找、第二輪要求它推翻站不住腳的發現），比較最終清單跟單輪掃描的品質差異。

- **跟你工作的關聯：** 你平常在 Claude Code 裡手動設定的 MCP server（例如 Figma、Linear、Sentry），未來可能直接從 Marketplace 一鍵安裝；反過來，你寫的內部工具也有機會包成 plugin 上架。
- **具體場景：** 前端團隊想讓 Claude 讀 Figma 設計稿、查 Sentry 錯誤、更新 Jira 票，與其每個人各自設定 `.mcp.json`，可以先去 Marketplace 找有沒有官方 connector，統一安裝與權限管理。
- **這週可以嘗試：** 逛一次 claude.com/marketplace，對照你目前 `.mcp.json` 裡手動設定的 server，看看哪些已經有官方版本可以替換；順便列出一個你們團隊常用、但還沒有 connector 的工具，作為之後自己做 plugin 的候選。

## Claude Code · Changelog

**版本號 / 日期：** 2.1.281 / September 23, 2026

**變更項目：**
- Added Claude apps gateway support for newer Claude Desktop keys in desktop policy blocks, including blockReadsOutsideWorkingDirectories and disableBypassPermissionsMode（Claude apps gateway 的 desktop 政策區塊支援新版 Claude Desktop 設定鍵，包含 `blockReadsOutsideWorkingDirectories` 與 `disableBypassPermissionsMode`）
- Added assume_role on Claude apps gateway Bedrock upstreams（gateway 的 Bedrock upstream 支援透過 STS assume IAM role，可跨 AWS 帳號，也可每位開發者一個 session）
- Added guardrail: {id, version} on Claude apps gateway Bedrock upstreams（可在 Bedrock upstream 上套用 Amazon Bedrock guardrail 到每個請求）
- Added telemetry.resource_attributes to the Claude apps gateway config（gateway 設定新增 `telemetry.resource_attributes`，替 Claude Desktop 與 /login session 的遙測資料加上固定標籤）
- Added "attribution": false in settings.json to hide all commit and PR attribution（settings.json 可設定 `"attribution": false` 一次隱藏所有 commit 與 PR 的署名；注意舊版 CLI 會略過含此設定的檔案，跨版本共用的設定檔請繼續用物件寫法）
- Added MCP URL-mode elicitation on 2026-07-28 protocol connections（MCP 新版協定連線支援 URL 模式 elicitation，server 可以請 Claude Code 開啟瀏覽器流程）
- Added MCP server checks to claude plugin validate（`claude plugin validate` 會檢查 `.mcp.json` 中會被靜默丟棄的項目、未宣告的 `${user_config.*}` 引用與不安全的 URL）
- Added an auto mode recommendation to /insights（`/insights` 會估算近期 session 中有多少權限提示可以交給 auto mode 處理）
- Added a scrollbar to the /skills, /mcp and /plugin Installed lists in fullscreen mode（fullscreen 模式下 `/skills`、`/mcp`、`/plugin` 已安裝清單新增可拖曳的捲軸）
- Fixed resumed sessions re-sending earlier turns in a changed form, which could make the API drop the conversation's prior reasoning; also fixed resuming a very large session sometimes restoring only its last few messages（修正 resume session 時重送的歷史內容被改變、導致前面推理被丟棄的問題，以及大型 session 只還原最後幾則訊息的問題）
- Fixed the prompt cache being lost when an MCP server disconnects mid-conversation, or after a restart during a pending permission prompt（修正 MCP server 中途斷線、或在權限提示等待中重啟後 prompt cache 失效的問題）
- Fixed responses cut short by a proxy or gateway being shown as complete with no warning, and tool calls running twice on duplicated stream events（修正經過 proxy / gateway 時回應被截斷卻顯示為完成、以及重複 stream 事件導致 tool call 執行兩次的問題）
- Fixed a recursive rm whose target is only command-substitution output, such as rm -rf "$(pwd)", running unprompted in auto and --dangerously-skip-permissions mode（修正 `rm -rf "$(pwd)"` 這類目標只來自指令替換的遞迴刪除，在 auto 與 `--dangerously-skip-permissions` 模式下未經詢問就執行的問題；現在即使有 Bash allow 規則也會詢問）
- Fixed claude --bg starting a background session, and running its project hooks, in a directory that had not passed the workspace trust prompt（修正 `claude --bg` 在尚未通過 workspace trust 的目錄啟動背景 session 並執行專案 hooks 的問題）
- Fixed a delay of up to two minutes before responding when reading or @-mentioning a PDF larger than 3 MB（修正讀取或 @ 提及超過 3 MB 的 PDF 時最多延遲兩分鐘的問題）
- Fixed pressing Shift+Tab twice quickly landing on the wrong permission mode（修正快速按兩次 Shift+Tab 會切到錯誤權限模式的問題）
- Fixed vim mode motions such as dj/dk/dG/dgg, 1G, d0/c0/y0 and cw edge cases（修正 vim 模式多個指令的邊界行為，包含 dj/dk/dG/dgg、1G、d0/c0/y0 與 cw 在空白、單字尾端等情境）
- Fixed scheduled tasks and /loop wakeups being fired again every second when their delivery failed（修正排程任務與 `/loop` 喚醒在送達失敗時每秒重複觸發的問題）
- 另有大量 plugin 管理、MCP 連線、Remote Control、`/model`、`/feedback`、agent panel 等細節修正（完整清單請見原文 changelog）

**核心概念（簡單說）：**
2.1.281 是一個以「穩定性」為主軸的大型維護版本。新功能集中在兩塊：一是企業部署的 Claude apps gateway（Bedrock assume_role、guardrail、遙測標籤、Desktop 政策鍵），二是開發者體驗的小改進（`"attribution": false` 一鍵關閉 commit 署名、plugin validate 檢查 MCP 設定、`/insights` 建議 auto mode）。

修正項目的重點則是「長 session 的可靠度」與「安全邊界」：大量修正圍繞 resume session 時歷史內容被改動、prompt cache 意外失效、proxy 截斷 stream 等問題——這些都會讓模型「失憶」或多花 token。安全面則修掉了 `rm -rf "$(pwd)"` 這種在 auto mode 下可能未經確認就執行的危險指令，以及未信任目錄下背景 session 執行 hooks 的漏洞。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你常用 auto mode 或讓 Claude Code 長時間跑任務、經常 resume session，這版能減少「中途失憶」與不必要的 token 浪費，也降低誤刪整個專案目錄的風險。
- **具體場景：** 你們公司透過內部 proxy 或 gateway 使用 Claude Code，之前偶爾遇到回應莫名中斷、tool call 重複執行（例如 `npm install` 跑兩次）的狀況，更新後應該會改善；若你不想在 commit 裡出現 AI 署名，也可以直接在 settings.json 設 `"attribution": false`。
- **這週可以嘗試：** 執行 `claude --version` 確認已更新到 2.1.281，接著跑一次 `/insights` 看看它估計 auto mode 能幫你省下多少權限提示；若你有自製 plugin，順手跑 `claude plugin validate` 檢查 `.mcp.json` 有沒有被靜默忽略的設定。
