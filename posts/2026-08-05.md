**原文：**
> Mariano-Florentino (Tino) Cuéllar will join Anthropic as its first Chief Global Affairs Officer, leading the company's work on policy, strategic international engagement, and government relationships worldwide.
>
> Tino's career spans law, technology, international security, and public institutions at the international, national, and state levels. He recently stepped down as President of the Carnegie Endowment for International Peace, a leading independent global policy research institution with scholars in 20 countries. Prior to his role at Carnegie, Tino was a Justice of the Supreme Court of California, where his opinions addressed technology and privacy, international agreements, and the separation of powers, among other issues. He was previously director of Stanford's Freeman Spogli Institute for International Studies, co-director of the university's Center for International Security and Cooperation, and director of the Stanford Cyber Initiative. He has served on the President's Intelligence Advisory Board and the US Department of State's Foreign Affairs Policy Board, and worked in the White House and federal agencies in three presidential administrations. The National Academy of Sciences appointed him to its Committee on Responsible Computing Research.
>
> Tino has served as a Trustee of Anthropic's Long-Term Benefit Trust since January 2026. He has stepped down from the Trust to join the company. The Trust will select a successor under its normal process.
>
> "Policymakers in the US and around the world are increasingly realizing that we are at a critical inflection point when it comes to how we govern and develop artificial intelligence... Democracies must set the terms on which this technology advances, and there is no more consequential place to be shaping that work right now than Anthropic," said Cuéllar.
>
> "Tino has spent his career helping public institutions respond to times of change with thoughtfulness, pragmatism, and deep commitment to the common good," said Daniela Amodei.

**繁中改寫：**
Mariano-Florentino（Tino）Cuéllar 即將加入 Anthropic，出任公司史上第一位「Chief Global Affairs Officer（全球事務長）」，負責政策、國際策略布局，以及跟世界各國政府的關係經營。

Tino 的職涯橫跨法律、科技、國際安全與公部門，層級從國際、國家到州級都有經歷。他先前是「卡內基國際和平基金會」（Carnegie Endowment for International Peace，一個在 20 個國家都有學者的獨立全球政策智庫）的院長，也曾任加州最高法院大法官，處理過科技與隱私、國際協議、三權分立等議題。他也做過史丹佛「Freeman Spogli 國際研究學院」院長、「國際安全與合作中心」共同主任，以及史丹佛網路安全計畫主任，並曾在總統情報顧問委員會、美國國務院外交政策委員會任職，橫跨三屆政府在白宮和聯邦機構工作過。

值得注意的是，Tino 從 2026 年 1 月起就是 Anthropic「Long-Term Benefit Trust（長期利益信託）」的受託人——這個信託是 Anthropic 治理結構中負責監督公司使命的獨立機制。他這次為了加入公司正式卸下受託人身份，信託會依正常程序選出繼任者。

**核心概念（簡單說）：**
這則新聞的重點不是產品發布，而是 Anthropic 在補強「公司治理與外部溝通」這塊拼圖。隨著 Claude 這類前沿 AI 模型的影響力越來越大，各國政府開始認真討論該怎麼監管、怎麼合作，Anthropic 需要一個專職角色去跟全球政策制定者打交道、談判、建立信任。找一位同時懂法律（曾任州最高法院大法官）、懂國際安全、又懂科技政策的人來坐這個位子，代表 Anthropic 預期接下來要花更多心力在「AI 治理」這條戰線上，而不只是把模型做得更強。另外一個值得留意的細節是：他原本是監督 Anthropic 使命的信託受託人，現在「跳槽」進公司內部做實際執行工作，某種程度上顯示這個治理與商業兩端的界線正在有意識地流動。

**前端工程師實際應用：**

## Claude Code · Changelog

**版本號 / 日期：** 2.1.222 / August 4, 2026

**變更項目：**
- Fixed worktree-isolated sessions and their subagents being able to run destructive git commands against the main checkout — 修復 worktree 隔離的 session 及其 subagent 竟然還能對「主要 checkout」執行破壞性 git 指令的漏洞，現在檔案編輯和 Bash 隔離會套用到每一種 session 類型。
- Fixed PreToolUse auto-allow hooks bypassing tool restrictions in background agent tasks (summaries, compaction, renames) — 修復背景 agent 任務（摘要、壓縮上下文、改名）中，`PreToolUse` 的 auto-allow hook 會繞過工具限制的問題。
- Fixed `/usage-credits` on Team and Enterprise incorrectly blocking members whose earlier request was dismissed from sending a new one — 修復 Team／Enterprise 方案的 `/usage-credits`，成員先前的額度請求被駁回後，會被誤判成「已經送出過」而卡住無法再送新請求。
- Fixed the startup connectivity check hanging and failing behind an HTTPS proxy — 修復在 HTTPS proxy 後方啟動時，連線檢查會卡住並失敗的問題，現在改用跟 API 請求一樣支援 proxy 的傳輸層，逾時也會顯示清楚訊息。
- Fixed "Connection closed mid-response" errors being reported on responses that had actually completed — 修復明明已經完整回應完畢，卻誤報「連線在回應中途被關閉」錯誤的問題。
- Fixed `/usage` overattributing usage to MCP servers — 修復 `/usage` 把用量灌水算到 MCP server 頭上的問題，現在只會計入該 server 實際提供工具結果被使用的請求，而不是呼叫過一次後每一輪都算它的。
- Fixed sessions not linking to pull requests created after the branch was pushed — 修復分支推送後才建立的 PR 沒有跟 session 連結的問題，包含透過 GitHub REST API 建立的 PR。
- Fixed org-restricted model: opus-style subagent and teammate family aliases dropping to the parent model instead of stepping down to the newest org-allowed model — 修復組織限制模型時，opus 系列的 subagent／teammate 別名會直接掉回「家族母模型」而非降級到組織允許範圍內最新的模型。
- Fixed stream idle timeout firing on custom `ANTHROPIC_BASE_URL` gateways despite server keep-alive pings arriving — 修復自訂 `ANTHROPIC_BASE_URL` gateway 明明有收到 keep-alive ping，串流閒置逾時還是誤觸發的問題。
- Fixed claude.ai connectors being falsely marked as needing authorization when the session token is invalid — 修復 session token 失效時，claude.ai connector 被誤判為「需要重新授權」，現在會改顯示 `/login` 提示。
- Fixed tool errors not being displayed for tools no longer available locally — 修復工具在本機已不存在時（例如 MCP server 被移除後），相關錯誤訊息不會顯示出來的問題。
- Fixed `SendMessage` rejecting a long summary — `SendMessage` 遇到過長摘要時改成自動截斷，不會再直接因為超過字數上限而送失敗。
- Fixed the spinner's effort label in a subagent's transcript view showing the session's effort level instead of the subagent's own — 修復 subagent 逐字稿畫面的轉圈圈 effort 標籤，顯示的其實是整個 session 的 effort，而不是該 subagent 自己的設定。
- Fixed rare crashes when a file watcher hit a filesystem error or during file-watcher teardown — 修復檔案監看器（file watcher）遇到檔案系統錯誤或關閉過程中偶發當機的問題。
- Fixed screen readers re-reading the whole input line on every backspace in `--ax-screen-reader` mode — 修復 `--ax-screen-reader` 模式下，每按一次 Backspace 螢幕報讀器就會整行重讀一次的問題，現在只會唸出被刪掉的字元。
- Fixed host model-selection keys not taking precedence over a stale on-disk `managed-settings.json` — 修復設定 `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` 時，host 端模型選擇設定沒有優先於硬碟上過期的 `managed-settings.json` 的問題。
- Improved auto mode safety: messages sent via `SendMessage` to other agent sessions are now evaluated by the permission classifier before dispatch — 強化 auto 模式安全性，透過 `SendMessage` 傳給其他 agent session 的訊息，發送前會先經過權限分類器檢查。
- Improved the refusal when Claude tries to invoke a skill with `disable-model-invocation` — 改善當 Claude 嘗試呼叫設有 `disable-model-invocation` 的 skill 時的拒絕訊息，現在會請你自己下指令執行該 skill，而不是自己模仿它的流程硬做。
- Improved `/diff` view, Remote Control workspace diff, and file-edit diffs in Claude Code on the web to use raw git blob content — 改善 `/diff` 畫面、Remote Control 的 workspace diff，以及網頁版 Claude Code 的檔案編輯 diff，統一改用原始 git blob 內容比對，不再受 workspace 自訂 diff driver 或 textconv 設定影響。
- Changed Remote Control auto-start so repo-local settings can no longer turn it on (they can still turn it off) — 調整 Remote Control 自動啟動規則：repo 內的 `.claude/settings.json` 或 `.claude/settings.local.json` 只能拿來關閉它，不能再用來打開，要開啟得在使用者層級用 `/config` 設定。
- Removed ultraplan feature — 移除 ultraplan 功能。

**核心概念（簡單說）：**
這個版本（2.1.222）是一次以「安全性與正確性補丁」為主的更新，重點是修掉幾個跟隔離、權限邊界有關的漏洞：像是 worktree 隔離 session 竟然能對主要 checkout 下破壞性 git 指令、auto-allow hook 在背景任務中會繞過工具限制、模型的組織限制在某些別名情境下失效等等，這些都是「原本設計要隔開的東西沒有隔好」的問題。另外也修了不少串流連線、額度計算、UI 顯示不準確的小毛病，並強化了 `SendMessage` 跨 session 通訊的安全檢查。整體來說，這個版本花很多力氣在讓 Claude Code 作為「可以在背景長時間自主運作的 agent」時，權限邊界跟隔離機制更可靠。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你有用 worktree 讓多個 Claude Code session 平行處理不同分支的任務，這次修復的「worktree 隔離漏洞」直接影響你的程式碼安全——之前有可能某個隔離 session 的 subagent 不小心對你的主要 checkout 動手。
- **具體場景：** 團隊用 Claude Code 背景跑多個平行任務（例如同時處理三個元件的重構），並透過 `SendMessage` 讓不同 agent session 互相通知進度，這次加強的權限分類檢查能降低訊息被濫用去觸發非預期操作的風險。
- **這週可以嘗試：** 升級到 2.1.222 後，如果你有在用 worktree-isolated session 跑背景任務，特地測一次「隔離是否真的隔離」——在隔離 session 裡故意下一個會動到 git 的指令，確認它現在真的動不了主要 checkout；同時也可以看看 `/diff` 畫面改用 raw git blob 後，你自訂的 diff driver（如果有設定 `.gitattributes` 的 textconv）顯示上有沒有變化。
