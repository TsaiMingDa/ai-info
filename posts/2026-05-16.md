## Claude Code · Changelog

### v2.1.143 / 2026-05-15

**變更項目：**
- Added plugin dependency enforcement: `claude plugin disable` now refuses when another enabled plugin depends on the target, with a copy-pasteable disable-chain hint（Plugin 依賴強制執行：停用 plugin 前會先檢查是否有其他 plugin 依賴它，並提示完整的停用順序）
- Added projected context cost (per-turn and per-invocation token estimates) to the `/plugin` marketplace browse pane（在 `/plugin` marketplace 頁面顯示每次呼叫的預估 token 費用）
- Added `worktree.bgIsolation: "none"` setting to let background sessions edit the working copy directly without `EnterWorktree`, for repos where worktrees are impractical（新增設定讓背景 session 直接在工作目錄操作，免去 worktree 限制）
- PowerShell tool now passes `-ExecutionPolicy Bypass` by default; opt out with `CLAUDE_CODE_POWERSHELL_RESPECT_EXECUTION_POLICY=1`（PowerShell 工具預設繞過執行政策限制）
- Background sessions now preserve the model and effort level after waking from idle（背景 session 從 idle 喚醒後保留模型與 effort 設定）
- Shift+Tab in attached agent sessions now includes auto mode in the cycle（Shift+Tab 切換模式加入 auto mode）
- Fixed worktree cleanup no longer falling back to `rm -rf`, preventing loss of gitignored files（worktree 清理不再使用 `rm -rf`，防止 gitignored 檔案意外遺失）
- Fixed background agents false-positive worker-stall detection after host sleep（修復 macOS 主機睡眠後背景 agent 誤判為 stall）
- Fixed background sessions silently capturing IDE file references into warm spare's input（修復 IDE 檔案參照被偷偷注入備用 session 的問題）
- Fixed 5xx error messages pointing at status.claude.com instead of configured gateway（修復錯誤訊息連結）
- Fixed multiple background session issues on macOS (`~/Documents`, `~/Desktop`, `~/Downloads` permissions) and Windows (right-click paste in `claude agents`, arrow key responsiveness)（修復 macOS 和 Windows 上多個背景 session 操作問題）
- `/bg` now preserves `--mcp-config`, `--settings`, `--add-dir`, `--plugin-dir`, and `--strict-mcp-config` flags（`/bg` 指令保留更多 flag 設定）
- Fixed stop hooks that block repeatedly looping forever (now caps at 8 consecutive blocks)（Stop hook 連續 block 上限改為 8 次，防止無限迴圈）

**核心概念（簡單說）：**
v2.1.143 是一次以穩定性為主的大型修復版本。最值得注意的是兩個改變：一是 plugin 依賴管理機制——就像 npm 停用套件前會告訴你「哪些東西依賴它」，現在 Claude Code 也會在你停用 plugin 前提供完整的停用鏈提示；二是 `worktree.bgIsolation: "none"` 設定，讓不使用 git worktree 的專案也能讓背景 agent 直接修改工作目錄，不再被預設的 worktree 隔離機制阻擋。

**前端工程師實際應用：**
- **跟你工作的關聯：** `worktree.bgIsolation: "none"` 對大多數前端專案很實用——很多 React/Vue 專案沒有使用 git worktree，這個設定讓背景 agent 可以直接在你的 `src/` 下修改程式碼；plugin 依賴管理則讓多 plugin 的複雜設定環境更安全
- **具體場景：** 在一個使用 Vite + React 的專案中，在 `.claude/settings.json` 加入 `"worktree": { "bgIsolation": "none" }`，然後用 `/bg 幫我修所有 ESLint 錯誤` 啟動背景 agent，讓它在你繼續開發時同步清理 lint 問題，不需要切換 worktree
- **這週可以嘗試：** 執行 `npm update -g @anthropic-ai/claude-code` 升級到最新版，然後測試 `/bg` 搭配 `--settings` flag，看看能否用不同的設定檔啟動背景 session，達到開發環境和 CI 環境分開管理的效果

### v2.1.142 / 2026-05-14

**變更項目：**
- Added new `claude agents` flags: `--add-dir`, `--settings`, `--mcp-config`, `--plugin-dir`, `--permission-mode`, `--model`, `--effort`, and `--dangerously-skip-permissions`（`claude agents` 命令新增多個啟動 flag，可直接指定模型、設定、權限等）
- Fast mode now uses Opus 4.7 by default (previously Opus 4.6)（Fast mode 預設模型從 Opus 4.6 升級至 Opus 4.7）
- Plugins with root-level `SKILL.md` and no `skills/` subdirectory now surfaced as a skill（根目錄有 `SKILL.md` 但無 `skills/` 子目錄的 plugin 現在自動作為 skill 顯示）
- `/plugin` details pane and `claude plugin details` now show LSP servers a plugin provides（plugin 詳情頁面顯示提供的 LSP server 資訊）
- `/web-setup` warns before replacing existing GitHub App connection（`/web-setup` 覆蓋現有 GitHub App 連結前會先警告）
- Fixed `MCP_TOOL_TIMEOUT` not raising per-request fetch timeout for remote HTTP and SSE MCP servers（修復 MCP_TOOL_TIMEOUT 對 HTTP/SSE MCP server 不生效的問題）
- Fixed background sessions disappearing after macOS sleep/wake（修復 macOS 睡眠喚醒後背景 session 消失的問題）
- Fixed daemon not exiting cleanly after binary upgrade（修復二進位升級後 daemon 無法乾淨退出的問題）
- Improved reactive compaction with better seed strategy（改善 reactive compaction 的 seed 策略，提升壓縮效果）
- Removed stale `/model claude-sonnet-4-20250514` suggestion from refusal messages（移除過時的模型建議）

**核心概念（簡單說）：**
v2.1.142 的最大亮點是 Fast mode 升級到 Opus 4.7——Fast mode 原本就是用 Opus 搭配更快的輸出速度，現在換上最新的 4.7 版本，意味著你在開啟 Fast mode 時能同時享有更強的推理能力。另外 `claude agents` 新增的多個 flag 讓你可以在啟動 agent dashboard 的同時直接帶入所有設定，不需要事先手動配置。

**前端工程師實際應用：**
- **跟你工作的關聯：** Fast mode 升級代表平時的快速問答和程式碼生成品質提升；`claude agents --model` flag 讓你可以針對不同任務指定不同模型，比如輕量任務用 Haiku、複雜重構用 Opus，在同一個 dashboard 下並行管理
- **具體場景：** 用 `claude agents --model claude-opus-4-7 --settings .claude/heavy-settings.json` 啟動一個專門跑大型重構任務的 agent session，同時用 `claude agents --model claude-haiku-4-5 --settings .claude/light-settings.json` 跑日常的 lint/format 任務，兩個 session 並行，互不干擾
- **這週可以嘗試：** 開啟 Fast mode（`/fast`），執行一個你平常覺得「還算夠用」的任務，感受 Opus 4.7 相比 4.6 在邊界情況（如複雜型別推導、多檔案依賴分析）上的差異
