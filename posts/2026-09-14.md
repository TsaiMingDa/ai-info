## Claude Code · Changelog

**版本號 / 日期：** 2.1.270 / September 12, 2026（此為最新版本，發布時間早於上次 digest，今日無更新版本）

**變更項目：**
- Fixed read-only git commands in Bash unexpectedly asking for permission after a session had been running for a while (regression in 2.1.269)
  （修正：session 執行一段時間後，唯讀的 git 指令在 Bash 中會意外跳出權限詢問，屬於 2.1.269 的迴歸問題）

**核心概念（簡單說）：**
這是一個純粹的回歸修復（regression fix）：上一版（2.1.269）引入的變更，意外導致原本不需要授權的唯讀 git 指令（例如 `git status`、`git log`）在 session 跑一段時間後開始跳出權限確認視窗，打斷開發流程。這版把這個問題修正回去，讓唯讀指令維持原本應有的免確認行為。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你常用 Claude Code 在終端機裡跑 git 指令輔助開發（查看 diff、確認分支狀態等），這類權限跳窗的 bug 會直接打斷你的工作節奏，是很貼近日常使用體驗的修正。
- **具體場景：** 假設你開了一個長時間的 pairing session 讓 Claude Code 幫你重構元件，過程中它需要頻繁用 `git diff` 確認變更範圍，這個 bug 會讓每次 diff 都跳出確認框，非常擾人；這版修好之後就能恢復順暢的長 session 體驗。
- **這週可以嘗試：** 升級到 2.1.270（或更新版本），確認 `claude --version` 是否已包含此修正；如果你有長時間執行的 session，可以順便觀察其他唯讀指令（如 `git log`、`git show`）是否也恢復正常。
