## Claude Code · Changelog

**版本號 / 日期：** 2.1.154 / 2026-05-28

**變更項目：**
- **Opus 4.8 支援** — Claude Code 現在以 Opus 4.8 作為預設模型，並加入 `/effort xhigh` 選項供最高難度任務使用（Opus 4.8 defaults to high effort）
- **Dynamic Workflows（研究預覽）** — 新功能：可讓 Claude 在背景協調數十到數百個 subagent 並行執行大型任務；使用 `/workflows` 查看執行狀態；適用 Pro、Max、Team、Enterprise 付費方案
- **Fast mode 降價** — Opus 4.8 的 fast mode 現在以標準費率 2 倍計費（之前更貴），速度約 2.5 倍，可用 `/fast` 開啟
- **Lean system prompt 成為新預設** — 除 Haiku、Sonnet 與 Opus 4.7 及更早版本外，lean system prompt 現在是所有 model 的預設
- **MCQ prompt 限縮** — Claude 現在只在真的無法自行決定時才問多選題，而不是在已有足夠 context 時也要問
- **`/code-review --fix` 改進** — review 完成後自動把建議套用到 working tree；新增重用性、簡化、效率等面向的建議
- **`/reload-skills` 指令** — 不需重啟 session 就能重新掃描 skill 目錄
- **Messages API 更新** — 現在接受在 messages array 內放入 system entries，讓 developer 可以在 agent 執行期間更新指令而不破壞 prompt cache
- 另包含 7 項新功能、5 項改進、3 項安全修復、24 項 bug 修復、1 項 deprecation

**核心概念（簡單說）：**
這次 2.1.154 是 Opus 4.8 發布的配套版本，最大的架構改變是 Dynamic Workflows——這是一種「meta-agent」能力，讓 Claude 不只是執行你給的任務，而是自己規劃任務的並行分工、啟動多個子 agent 各自負責不同部分，最後匯整結果。概念上類似把 Claude Code 從「單線程執行者」升級成一個可以管理工作隊的「project manager」。對前端工程師來說，這意味著以前需要手動分批進行的大型 migration，現在可能可以一個指令就交給 Claude 全部包辦。

**前端工程師實際應用：**
- **跟你工作的關聯：** Dynamic Workflows 直接影響你能委託給 Claude Code 的任務規模上限。原本「太大、太複雜，得自己拆解」的任務（例如全站 TypeScript 嚴格模式遷移、大型 design token 重構），現在有機會直接說「幫我做完」。
- **具體場景：** 你需要把整個 React 專案的 class components 全部升級成 functional components + hooks，涉及上百個檔案。輸入任務描述後讓 Claude 用 dynamic workflows 協調多個 agent 並行掃描、改寫、驗證，自己去做別的事，等它完成後再 review。
- **這週可以嘗試：** 跑 `claude update` 確認是 2.1.154 以上版本，然後輸入 `/workflows` 看看這個功能在你的 plan 是否已啟用（Pro/Max/Team/Enterprise 才支援），接著設計一個你一直懶得手動做的大型重構任務來測試。
