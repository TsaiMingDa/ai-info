## Claude Code · Changelog

**版本號 / 日期：** 2.1.185 / June 20, 2026

**變更項目：**
- The stream-stall hint now reads "Waiting for API response · will retry in …" instead of "No response from API · Retrying in …", and triggers after 20s of silence instead of 10s（API 等待提示改用更清楚的措辭，觸發門檻從 10 秒延長至 20 秒）

**核心概念（簡單說）：**
這次更新是小幅 UX 修正。當 Claude Code 等待 API 回應時，舊提示語 "No response from API · Retrying in …" 容易讓人以為 API 已失敗；新措辭 "Waiting for API response · will retry in …" 更準確傳達「還在等，還沒掛」。觸發時間也從 10 秒改為 20 秒，避免短暫的 API 延遲就立刻跳出提示讓人分心。

**前端工程師實際應用：**
- **跟你工作的關聯：** 在用 Claude Code 跑大型任務（例如全專案 refactor、長時間 code review）時，API 延遲很常見。新提示讓你更明確知道 Claude 還在運作中，不是死掉了，減少不必要的焦慮或手動中斷。
- **具體場景：** 執行 `claude "refactor all API call patterns in src/ to use async/await"` 這類長任務時，若 API 一時慢，舊版 10 秒就會跳出 "No response from API"，容易讓人誤以為要重來；新版等 20 秒才提示，且措辭改成「正在等待」，流程更平順。
- **這週可以嘗試：** 跑一個比較耗時的 Claude Code 任務，觀察若 API 有延遲時提示訊息的新措辭，感受一下 UX 改善。也可以在慢網路環境下測試，驗證 20 秒的新門檻對你的工作流影響。
