## Claude Code · Changelog

**版本號 / 日期：** 2.1.146 / 2026-05-21

**變更項目：**
- `/simplify` 改名為 `/code-review`，支援可選力度參數（例如 `/code-review high`）
- Auto mode 不再在 user 或 skill 明確依賴 `AskUserQuestion` 時壓制它
- 修復：Windows 上透過 winget 或 Microsoft Store 安裝的 `pwsh` 執行 PowerShell tool 時報 "command line is invalid"（v2.1.124 regression）
- 修復：MCP `resources/list`、`resources/templates/list`、`prompts/list` 在有分頁的 server 上第 1 頁後的項目遺失
- 修復：Windows Terminal 的 attached background session 在 Claude 串流時全屏閃爍（strobing）
- 修復：auto-updater 狀態欄在更新失敗時未顯示目前版本
- 修復：Windows 上刪除 background-job worktree 時不再透過 NTFS junction 誤入主 repo
- 修復：`/background` 拒絕只輸入了 skill 或自訂 slash command 的 session
- 修復：已用「don't ask again」授權的工具權限在 backgrounded session 重複提示
- 修復：`/theme` 顏色編輯器與「New custom theme」對話框不響應 Esc
- 修復：透過 Agent SDK 執行時，streaming session 結束時的未捕捉 exception
- 修復：`forceLoginOrgUUID` 與 `forceLoginMethod` managed-settings policies 對第三方 provider 和 API key session 未正確執行
- 修復：GNOME Terminal 右鍵和中鍵貼上不插入文字
- 修復：multi-agent session 中 `CLAUDE_CODE_SUBAGENT_MODEL` 未傳遞給子行程
- 改善：auto-updater 可靠性 — 版本檢查和下載在瞬時網路失敗時自動重試而非立即失敗
- 改善：大型檔案編輯的 diff 渲染效能

**核心概念（簡單說）：**
這次 2.1.146 最顯眼的改動是 `/simplify` 正式更名為 `/code-review`，並加了 effort level 選項（如 `high`）。改名讓語義更準確——不是「幫我簡化」，而是「幫我做程式碼審查」；effort level 則讓你可以選擇快速掃描還是深入分析。把 `/code-review high` 想成「請幫我認真 review 到底，不要放水」，省略參數就是一般力度的快速審查。

另一個值得注意的修正：auto mode 不再壓制 `AskUserQuestion`。過去如果你的 skill 流程中設計了「需要 Claude 中途問你問題」的步驟，auto mode 有時會直接跳過這個交互，導致 skill 邏輯跑歪。這次修正讓 skill 的設計意圖可以被正確執行，對自訂了複雜 skill 的用戶影響明顯。

其餘是大量 bug fix，以 Windows 環境（PowerShell、NTFS junction、GNOME Terminal）、MCP 分頁、background session 穩定性為主，整體是基礎設施層面的強化。

**前端工程師實際應用：**
- **跟你工作的關聯：** `/code-review` 讓你在提交 PR 前可以直接在 Claude Code 裡審查自己寫的 React 組件、TypeScript utility 或 CSS 邏輯，不需要切換工具。`high` 力度尤其適合複雜功能上線前的最終把關，能找出 shallow review 容易漏掉的問題。
- **具體場景：** 你改完一個用 `useCallback` 和 `useMemo` 優化的列表組件，不確定依賴陣列有沒有遺漏或是否存在不必要的 re-render。在 Claude Code 裡直接跑 `/code-review high`，讓 Claude 以嚴格標準審查，通常能抓出 diff review 不容易發現的效能問題和邏輯漏洞。
- **這週可以嘗試：** 找一個你最近寫的前端功能，先跑 `/code-review`（預設力度），再跑 `/code-review high`，對比兩次回饋的深度差異，感受 effort level 的實際效果。同時確認 `claude --version` 已是 v2.1.146。
