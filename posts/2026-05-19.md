## Claude Code · Changelog

**版本號 / 日期：** v2.1.144 / 2026-05-19

**變更項目：**

主要新功能：
- **`/resume` 支援背景 session**（Added `/resume` support for background sessions）：透過 `claude --bg` 或 agent view 啟動的 session，現在會和互動式 session 一起列出，標記為 `bg`
- **背景 subagent 完成通知加入執行時間**（Added elapsed duration to background subagent completion notifications）：例如顯示「Agent completed · 3h 2m 5s」
- **`/plugin` browse 與 discover 面板顯示更新時間**（plugin browse/discover panes now show when a plugin was last updated）
- **`/model` 改為只影響目前 session**（`/model` now changes the model for the current session only）：在 model picker 中按 `d` 可設定新 session 的預設 model
- **「extra usage」更名為「usage credits」**（Renamed "extra usage" to "usage credits"）：`/extra-usage` 指令現在是 `/usage-credits`，舊名稱仍可正常使用

Bug 修復：
- 修正 `api.anthropic.com` 無法連線時（captive portal、防火牆、VPN），啟動最久會 hang 75 秒的問題——side-channel API call 現在 15 秒後 timeout（Fixed startup hanging up to 75s when api.anthropic.com is unreachable）
- 修正遺漏 window-resize event 後終端機輸出亂碼，現在下一個 frame 自動修復，不需要 Ctrl+L（Fixed garbled terminal output after a missed window-resize event）
- 修正超長 session 可能出現的殘影亂碼問題（Fixed progressive terminal display corruption）
- 修正 macOS 背景 session 在 Full Disk Access 保護目錄下崩潰（Fixed macOS background sessions crashing with "exit 1 before init"）
- 修正讀取副檔名與內容不符的圖片時整個對話變無法使用，現在 fallback 到純文字（Fixed unrecoverable conversation when reading a file whose image extension doesn't match contents）
- 修正 `/branch` 在 worktree 或某些背景 session 中失敗（Fixed `/branch` failing with "No conversation to branch"）
- 修正在 AskUserQuestion notes 欄位按 Escape 會直接中止 turn 而非回到答案選擇（Fixed pressing Escape in the AskUserQuestion notes field aborting the turn）
- 修正 IDE model picker 或 `applyFlagSettings` 變更 model 後不生效（Fixed model selection not applying when changed via IDE model picker）
- 修正 resumed session 會繼承另一個 session 的 `/model` 設定（Resumed sessions now keep the model they were using）

MCP 修復：
- 修正 MCP server 的 `tools/list` 有分頁時只回傳第一頁，靜默丟失後面的工具（Fixed MCP servers with paginated tools/list responses only returning the first page）
- 修正不支援的 MIME type 圖片（如 SVG）造成對話中斷，現在存到磁碟並在 tool result 中引用（Fixed MCP images with unsupported MIME types breaking the conversation）
- 修正 `.mcp.json` 無法解析時 `claude mcp list` 靜默顯示無 server（Fixed claude mcp list silently reporting no servers when .mcp.json can't be parsed）
- 修正自訂 `ANTHROPIC_BASE_URL` 和 Bedrock Mantle 的背景 side-queries 沒有使用 Haiku（Fixed background side-queries on custom ANTHROPIC_BASE_URL and Bedrock Mantle）

Terminal / UI 修復：
- 修正 Windows 上附加背景 session 後 PgUp/PgDn、滑鼠滾輪、Ctrl+O 捲動失效（Fixed scrolling in attached background sessions on Windows）
- 修正關閉終端機時崩潰（Fixed crash when closing the terminal while attached to a background session）
- 修正 `! <cmd>` exec session 在附加狀態下 Ctrl+C 無效（Fixed `! <cmd>` exec sessions not responding to Ctrl+C while attached）
- 修正 Windows ← 鍵在 `claude agents` 畫面後鍵盤失效（Fixed pressing ← in claude agents leaving the list unresponsive）
- 修正 Windows Terminal 的 CJK 內容在切換 pane 時出現殘影（Fixed ghost characters with CJK content on Windows Terminal）

**核心概念（簡單說）：**
v2.1.144 是一個以穩定性為主軸的版本，重點在兩個方向：**背景 session 改善**和**大量 bug 修復**。

最值得注意的功能是 `/resume` 現在支援背景 session——你可以在背景跑多個長時間的 Claude 任務，然後用 `/resume` 選擇接回哪個，而且完成通知還會顯示執行了多久（例如「3h 2m 5s」），幫助你規劃後續工作。另一個很實際的修復是 startup hang：如果你在 VPN 或公司網路環境下，之前 Claude Code 啟動可能要等最久 75 秒，現在最多 15 秒。

MCP 那邊修了一個容易被忽略的 silent bug：如果你的 MCP server 工具列表有分頁（工具數量超過單頁限制），之前只會拿到第一頁，剩下的工具被靜默丟失，完全沒有錯誤提示。這可能是導致「奇怪的 MCP 工具消失」問題的根本原因。

**前端工程師實際應用：**
- **跟你工作的關聯：** `/model` 指令現在只影響目前 session，你可以針對特定高難度任務（如複雜的 TypeScript 重構）臨時切換到 Opus，而不影響其他 session 的預設 model，讓多視窗工作流更彈性。
- **具體場景：** 你有一個 MCP server 整合了 Figma token、設計稿讀取等自訂工具，但最近發現某些工具偶爾消失——很可能就是分頁 bug 造成的。升級到 v2.1.144 後，如果你的 MCP server 工具數超過單頁限制，現在能保證全部工具都正確載入。
- **這週可以嘗試：** 用 `claude --bg` 啟動一個長時間的背景重構任務（例如把整個專案的 CSS module 換成 Tailwind），然後離開去做別的事，等 Claude 通知任務完成時（會顯示執行時間），再用 `/resume` 接回來 review 結果——這是讓 Claude 幫你跑大型任務而不佔用你注意力的最佳方式。
