## Claude Code · Changelog

**版本號 / 日期：** 2.1.215 / July 19, 2026

**變更項目：**
- Changed: Claude 不再自動執行 `/verify` 與 `/code-review` 這兩個 skill，改為需要你自己手動輸入 `/verify` 或 `/code-review` 才會觸發。

**核心概念（簡單說）：**
這個版本很單純：把「自動驗證」與「自動 code review」這兩個原本會被 Claude 自主判斷、主動觸發的 skill，改成完全由使用者手動呼叫。換句話說，Claude 不會再自己決定「這段程式碼看起來該跑一下 `/verify` 或 `/code-review` 了」，而是把主導權交還給開發者，避免這兩個相對耗時、耗 token 的流程在你沒預期的時候被自動插入。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你習慣讓 Claude Code 自主判斷何時該驗證或審查程式碼改動，升級後這個自動化行為會消失，你需要自己記得在關鍵時機呼叫這兩個指令，否則品質把關的步驟可能會被漏掉。
- **具體場景：** 例如你請 Claude 改完一個表單元件的邏輯後，過去它可能會自動跑一次 `/code-review` 幫你抓明顯的問題；現在升級到 2.1.215 之後，你需要自己在改動完成後手動輸入 `/code-review`，才會觸發這道檢查。
- **這週可以嘗試：** 把 `/verify` 與 `/code-review` 加進你自己的開發習慣或 checklist（例如每次改完一個功能、要 commit 前手動跑一次），必要時也可以考慮寫成 hook 或 slash command 串接，避免因為改成手動觸發而漏掉品質把關的步驟。
