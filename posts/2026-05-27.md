> the basic trick to using Claude Code for non-technical work is to put a bunch of files in a folder and tell it can write scripts + make HTML

**繁中改寫：**
用 Claude Code 處理非技術工作的基本技巧，就是把一堆檔案丟進一個資料夾，然後告訴它可以寫 script 跟產生 HTML。圖片或影片編輯？寫 script。財務、稅務？把 PDF 丟進去，寫 script，輸出 HTML。醫療資訊？放 PDF 和資料，輸出 HTML。填表格？寫 script。做報告？寫 HTML。做計畫？寫 HTML。讓它存取資料也很重要，可以接上 Gmail、Google Calendar 等 connector。但大家低估了自己在檔案裡已經擁有多少 context。

**核心概念（簡單說）：**
Thariq 點出了一個很實際的使用模式：Claude Code 不只是給工程師寫程式用的，它的核心能力在於「讀檔案 → 寫 script → 輸出結果」這個通用工作流。把它想成一個能自己寫工具的助手——你把資料（PDF、圖片、文字檔）丟給它，它自己寫出處理邏輯（Python script、Node script），再把結果輸出成人類易讀的格式（HTML）。這個模式之所以強大，是因為幾乎所有知識工作都能被拆解成「輸入資料 → 處理 → 輸出」的流程，而 Claude Code 可以自動完成中間的「處理」步驟。

**前端工程師實際應用：**
- **跟你工作的關聯：** 前端工程師經常需要處理非程式碼的工作——整理設計稿資訊、產生報告、處理 CSV 資料、將 Figma 規格轉成文件。這些都可以用「丟檔案進資料夾 + Claude Code 寫 script」的模式來自動化。
- **具體場景：** 你收到 PM 給的 10 份 PDF 競品分析報告，需要整理成一份比較表。把 PDF 都丟進一個資料夾，用 Claude Code 說「讀取所有 PDF，提取每個產品的功能列表、價格、優缺點，輸出一個 HTML 比較表格」，它會自己寫 Python script 用 `pdfplumber` 解析 PDF，再輸出一個漂亮的 HTML 表格。
- **這週可以嘗試：** 找一個你手邊重複性高的非程式碼任務（例如整理會議紀錄、處理 expense report），建一個資料夾把相關檔案丟進去，然後用 Claude Code 試著自動化它。先從小任務開始，感受「檔案 → script → 輸出」這個流程。

## Claude Code · Changelog

**版本號 / 日期：** 2.1.152 / May 27, 2026

**變更項目：**

新功能：
- `/code-review --fix` now applies review findings to your working tree after the review, surfacing reuse, simplification, and efficiency suggestions; `/simplify` now invokes `/code-review --fix`（`/code-review --fix` 現在會直接把 review 建議套用到你的程式碼，自動修正重複、簡化和效能問題；`/simplify` 現在直接呼叫 `/code-review --fix`）
- Skills and slash commands can now set `disallowed-tools` in frontmatter to remove tools from the model while the skill is active（skill 和 slash command 現在可以在 frontmatter 設定 `disallowed-tools`，在 skill 啟用時移除特定工具）
- Added `/reload-skills` command to re-scan skill directories without restarting the session（新增 `/reload-skills` 指令，不用重啟 session 就能重新掃描 skill 目錄）
- `SessionStart` hooks can now return `reloadSkills: true` to re-scan skill directories, making skills installed by the hook available in the same session（`SessionStart` hook 現在可以回傳 `reloadSkills: true` 來重新載入 skill）
- `SessionStart` hooks can now set the session title via `hookSpecificOutput.sessionTitle` on startup and resume（`SessionStart` hook 現在可以設定 session 標題）
- Added a `MessageDisplay` hook event that lets hooks transform or hide assistant message text as it is displayed（新增 `MessageDisplay` hook event，可以在訊息顯示時轉換或隱藏內容）
- Added `pluginSuggestionMarketplaces` managed setting: admins can allowlist org marketplaces whose plugins may be suggested via context-aware tips（新增 managed setting 讓管理員控制 plugin marketplace 建議）
- `claude plugin marketplace remove` now accepts `--scope user|project|local` for symmetry with `marketplace add`, `install`, and `uninstall`（`claude plugin marketplace remove` 新增 `--scope` 參數）
- Claude Code now switches to your configured `--fallback-model` for the rest of the session when the primary model is not found, instead of failing every request（主要模型找不到時，自動切換到 fallback model 而非每次都失敗）
- Auto mode no longer requires opt-in consent（Auto mode 不再需要選擇同意）
- Vim mode: `/` in NORMAL mode now opens reverse history search (like Ctrl+R), matching bash/zsh vi-mode（Vim 模式下 `/` 現在會開啟反向歷史搜尋）
- The `/usage` breakdown now includes large session files; files are scanned with a streaming read so memory usage stays flat（`/usage` 現在包含大型 session 檔案，使用 streaming 讀取避免記憶體暴漲）
- Thinking summaries in the collapsed group now stay readable for at least 3 seconds, render as markdown, and cap at 10 lines（思考摘要現在至少顯示 3 秒、支援 markdown 渲染、上限 10 行）
- In fullscreen mode, the "Thinking for Ns" indicator now counts up live while the model is thinking（全螢幕模式下思考時間指示器會即時計數）
- Simplified the Workflow tool's inline progress display（簡化 Workflow 工具的行內進度顯示）
- The post-response timer now shows "Waiting for N background agents/workflows to finish"（回應後計時器現在會顯示正在等待的背景 agent/workflow 數量）
- Added the session entrypoint as an OpenTelemetry metric attribute（新增 session entrypoint 作為 OpenTelemetry metric attribute）

修正：
- Fixed terminal styling degrading in very long sessions by recycling the renderer's style pool（修正長時間 session 中終端樣式退化問題）
- Fixed the sandbox-enabled warning not appearing in condensed startup mode（修正精簡啟動模式下 sandbox 警告不顯示）
- Fixed the loading spinner showing "still thinking" while a tool is running（修正工具執行中 spinner 顯示「still thinking」）
- Fixed focus mode showing a spurious "N messages hidden" count（修正 focus mode 錯誤的隱藏訊息計數）
- Fixed clicking a link inside an expanded tool result collapsing the section（修正點擊展開的工具結果中的連結會收合區塊）
- Fixed markdown table cell borders and styling issues（修正 markdown 表格框線和樣式問題）
- Fixed plugin MCP servers with the same command but different environment variables being incorrectly deduplicated（修正同指令但不同環境變數的 plugin MCP server 被錯誤去重）
- Fixed `cache_creation_input_tokens` reporting as 0（修正 cache_creation_input_tokens 回報為 0）
- Fixed the PushNotification tool incorrectly reporting "Mobile push not sent" in SDK-hosted sessions（修正 PushNotification 在 SDK session 的錯誤回報）
- Fixed sessions getting stuck after a model or login switch left stale thinking-block signatures（修正切換模型或登入後 session 卡住的問題）

**核心概念（簡單說）：**
這是一次非常大的更新（33 項 CLI 變更）。最重要的兩個亮點是：第一，`/code-review --fix` 讓 code review 從「只看不動手」進化成「看完直接改」，自動幫你套用 reuse、simplification 和效能建議。第二，skill 和 slash command 的 `disallowed-tools` frontmatter 讓你能精確控制 AI 在特定情境下可以使用哪些工具，這對建構安全、可預測的自動化流程非常關鍵。另外 Auto mode 不再需要 opt-in、fallback model 自動切換、以及大量的 hook 擴充（`MessageDisplay`、`SessionStart` 新能力）都讓 Claude Code 的自動化和客製化能力更上一層。

**前端工程師實際應用：**
- **跟你工作的關聯：** `/code-review --fix` 直接影響你的日常開發流程——每次寫完一個 feature 或修完 bug，跑一次就能自動清理重複程式碼、簡化邏輯、提升效能，省去手動 refactor 的時間。`disallowed-tools` 則讓你在寫自訂 skill 時能限制 Claude 的行為，例如讓一個「只讀分析」的 skill 無法執行寫入操作。
- **具體場景：** 你剛完成一個 React component 的重構，跑 `/code-review --fix`，它會自動找出重複的 useEffect pattern、可以用 custom hook 取代的邏輯、不必要的 re-render，然後直接幫你改好。或者你寫了一個 `/analyze-bundle` 的 skill，在 frontmatter 加上 `disallowed-tools: [Edit, Write]` 確保它只能分析不能修改檔案。
- **這週可以嘗試：** 更新 Claude Code 到 2.1.152，在你目前正在開發的 branch 上跑 `/code-review --fix`，看看它能找到哪些可以自動改善的地方。也可以試試 `/simplify` 指令（現在等同於 `/code-review --fix`），對一個你覺得有點複雜的檔案試試看效果。
