**版本號 / 日期：** 2.1.271 / September 14, 2026

**變更項目（精選重點，原文為英文）：**
- Added per-command allowed_domains to Bash, PowerShell and Monitor in auto mode with sandboxing: the hosts a command needs are reviewed with it and opened for it alone; other hosts are refused（沙箱模式下，Bash/PowerShell/Monitor 現在可以針對單一指令設定允許存取的網域，而不是整個 session 共用一份白名單）
- Added fast mode in Claude Code Remote sessions (cloud and self-hosted runners)（Remote 遠端 session，包含雲端與自架 runner，現在支援 fast mode）
- Added mouse support to the /config panel in fullscreen mode（全螢幕模式下 /config 面板現在支援滑鼠操作：滾輪捲動、點擊切換設定值）
- Fixed Bash permission checks missing the file that fmt, column and similar commands read when it follows an option the checker doesn't recognize（修正 Bash 權限檢查在某些指令後面接不認得的參數時，會漏掉實際要讀取的檔案）
- Fixed Bash permission checks skipping files a wildcard expands to when the wildcard sits in a command's pattern or option value（修正萬用字元展開的檔案在權限檢查中被跳過的問題，例如 `grep -v dir/* file`）
- Fixed a stale .git/config.lock breaking git checkout -b, git push -u and git config for the rest of a session after a sandboxed command failed to start (Linux)（修正 Linux 上沙箱指令啟動失敗後，殘留的 .git/config.lock 會讓同一 session 後續的 git 指令全部失敗）
- Fixed Claude starting a second copy of a background command (such as a watch task or dev server) that was still running after the conversation was compacted（修正對話被壓縮後，Claude 會重複啟動已經在背景執行的 watch task 或 dev server）
- Fixed --resume dropping the 1M context window ([1m]) when the resumed session's model family differs from the configured default model（修正 --resume 在恢復的 session 模型家族跟目前設定的預設模型不同時，會遺失 1M context window 設定）
- Fixed the interactive /hooks menu crashing when a hook matcher is named after an inherited object property such as __proto__ or constructor（修正互動式 /hooks 選單在 hook matcher 命名剛好撞到 __proto__、constructor 這類繼承屬性名稱時會當機）

**核心概念（簡單說）：**
這個版本份量很重，重點分兩大類：一是安全性與沙箱模式的精細化（例如新增 per-command 的網域白名單），讓自動模式下的指令執行更安全、更細緻；二是大量修正 Bash/PowerShell 權限檢查、git 操作、background 任務管理等日常開發流程中會踩到的邊角案例 bug，整體目的是讓 Claude Code 在自動化、免確認的情境下跑起來更可靠。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果有用 auto 模式搭配 sandboxing 讓 Claude Code 自動跑指令（例如自動跑測試、build、lint），新的 per-command allowed_domains 能讓沙箱設定更精準，不用整個 session 開一個大白名單。
- **具體場景：** 專案如果常需要下含萬用字元的指令（例如 `grep -v dist/* src`），這次修正讓權限檢查不會再漏掉萬用字元展開後的實際檔案，避免誤放行或誤擋。
- **這週可以嘗試：** 更新到 2.1.271 以上版本後，檢查目前的 sandbox 權限設定，評估要不要改用新的 per-command allowed_domains 讓權限控制更細；同時留意背景 dev server 在對話被壓縮（compact）後是否還是只跑一份。
