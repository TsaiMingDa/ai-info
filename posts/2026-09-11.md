## Claude Code · Changelog

**版本號 / 日期：** 2.1.268 / September 10, 2026

**變更項目：**
- Added browser-tab icons for published artifacts, chosen by Claude to match each page（新增：Claude 發布的 artifact 現在會自動配上瀏覽器分頁圖示，由 Claude 依頁面內容挑選）
- Fixed WebFetch hanging indefinitely on a server that keeps the response open without finishing; a fetch now fails after 300 seconds（修正：WebFetch 遇到不結束回應的伺服器會無限卡住的問題，現在 300 秒後會自動逾時失敗，可用 `CLAUDE_CODE_WEBFETCH_DEADLINE_MS` 調整逾時時間）
- Fixed Claude sometimes replying "your message came through empty" after an MCP tool call（修正：呼叫 MCP 工具後，Claude 有時會誤回覆「你的訊息是空的」的問題）
- Fixed sustained high CPU usage: a busy loop in long-running idle sessions no longer pins a CPU core（修正：長時間閒置的 session 會讓 CPU 使用率飆高的問題）
- Improved fullscreen mode: adding or removing a prompt line (Shift+Enter) now repaints as fast as typing a character（改進：全螢幕模式下用 Shift+Enter 換行的重繪速度，現在跟打字一樣快）
- Improved --continue / --resume: the conversation appears immediately instead of waiting for SessionStart hooks（改進：`--continue` / `--resume` 現在會立即顯示對話內容，不用等 SessionStart hook 跑完）
- Improved Claude in Chrome: long page reads now stay inline instead of being saved to a file and read back（改進：Claude in Chrome 讀取長網頁內容時，現在會直接顯示在對話中，而不是存成檔案再讀回來）
- Improved /plugin: installing, enabling or disabling a plugin now takes effect when you close the menu; /reload-plugins is no longer needed afterwards（改進：安裝、啟用、停用 plugin 後關閉選單就會立即生效，不用再手動跑 `/reload-plugins`）
- [VSCode] Added Left and Right arrow keys to change where an always-allow permission rule is saved, for keyboard and screen reader users（新增：VSCode 中可用左右鍵切換「一律允許」權限規則要存的位置，方便鍵盤與螢幕報讀器使用者操作）

**核心概念（簡單說）：**
這次更新的重點集中在「順手度」與「穩定性」的細節打磨：全螢幕模式打字更流暢、`--resume` 秒開對話、外掛安裝後不用再手動重載，這些都是高頻操作的體感優化。另外也修了幾個會讓人抓狂的 bug（WebFetch 卡死、CPU 飆高、MCP 呼叫後訊息消失），代表團隊持續在處理長時間使用 Claude Code 過程中累積的邊角案例。VSCode 與無障礙（accessibility）相關的改動也不少，顯示團隊有在照顧鍵盤操作與螢幕報讀器使用者的體驗。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你日常大量使用 Claude Code 的全螢幕模式或 `--resume` 接續對話，這次更新直接改善的是你每天都會碰到的操作體感，值得升級後感受一下差異。
- **具體場景：** 假設你常常一次開好幾個長時間跑的 session（例如背景跑測試、同時開好幾個 agent），這次修的「閒置 session CPU 飆高」問題，對你電腦風扇轉速應該會有感。
