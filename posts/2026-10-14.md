## Claude Code · Changelog

**版本號 / 日期：** 2.1.299 / October 14, 2026

**變更項目：**
- Added `CLAUDE_CODE_DISABLE_FILE_MENTIONS` environment variable: Claude gets the paths of @ file mentions to read with its file tools, not the files' contents — 新環境變數：`@` 提及檔案時只給 Claude 路徑，由它自己用檔案工具讀，而不是直接把內容塞進 prompt。
- Added idle compaction in the terminal: a 200K+ token conversation left idle for about 54 minutes is compacted before its one-hour prompt cache expires, so your next message doesn't reprocess it all — 終端機新增閒置壓縮：超過 200K token 的對話閒置約 54 分鐘時，會在一小時 prompt cache 過期前先壓縮，下一則訊息就不必整段重新處理。
- Added `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` to change idle compaction's 200K-token minimum; `"idleCompaction": false` in settings.json turns it off — 可調整閒置壓縮的 200K 門檻，或在 `settings.json` 設 `"idleCompaction": false` 關閉。
- Added `/effort` and `/fast` in agent view to set what new sessions start with; a bare `/model`, `/effort` or `/fast` there now opens a picker — agent view 可用 `/effort`、`/fast` 設定新 session 的預設值；不帶參數時會開選單。
- Added a one-time note when plan mode won't ask before most edits or commands because bypass permissions is available — 當 bypass permissions 可用、plan mode 不會在多數編輯／指令前詢問時，會顯示一次提醒。
- Added `--disallow-tools` and a `disallowed_tools` case field to `claude plugin eval` — plugin eval 可排除特定內建工具（例如 Agent）。
- Added `/usage` warnings for max effort, workflows, always-on context and large tool results — `/usage` 會針對 max effort、workflow、常駐 context、大型工具結果提出用量警告。
- Added `$.prompt.media`, `$.session.identity()`, Text `size`/`weight`/`mono`/`tabular` and Box spacing steps for mods — mods 新增讀取附件、session 身分、文字排版與間距等 API（`bold` 改用 `weight`）。
- Changed MCP allow rules to reach only the server they name: `mcp__a` no longer allows a server named `a__b` or `a_` — MCP 權限規則只比對完整 server 名稱，`mcp__a` 不再意外放行 `a__b`。
- Changed requests to claude.ai's connector proxy and to Anthropic-hosted MCP servers to no longer follow HTTP redirects — connector proxy 與 Anthropic 託管 MCP server 的請求不再跟隨 HTTP redirect。
- Changed UserPromptSubmit hooks to run before a skill or custom slash command expands, so a hook that blocks the prompt now also stops its embedded shell commands — `UserPromptSubmit` hook 改在 skill／自訂 slash command 展開前執行，擋下 prompt 時也會擋住其中內嵌的 shell 指令。
- Changed the resume command printed at exit: it names the session by its ID and no longer by its name — 結束時印出的 resume 指令改用 session ID，避免 session 名稱中的字元在貼上時被執行。
- Changed skill and command loading: one whose file or folder name has hidden, direction-changing or blank-like characters, `<` or `>` is no longer offered until renamed — 檔名含隱藏字元、方向控制字元或 `<`、`>` 的 skill／command 不再載入。
- Changed the errors shown when `/ultrareview` can't upload a repository to stop suggesting `git add .`, which could stage or commit untracked files such as `.env` — `/ultrareview` 上傳失敗的錯誤訊息不再建議 `git add .`，避免誤把 `.env` 加進 commit。
- Changed WebFetch page reads to pick their effort as web searches do — WebFetch 讀頁面的 effort 等級改與 web search 一致。
- 另含 Claude Tag、Cloud sessions、self-hosted runner、plugin hooks 等多項變更，以及 16 項改善、131 項 bug 修正（詳見原始 changelog）。

**核心概念（簡單說）：**
這版主軸是「長對話的成本」與「安全邊界收緊」。Idle compaction 解決的是一個很實際的痛點：Claude 的 prompt cache 大約一小時過期，如果你開著一個 300K token 的大 session 去開會，回來打一句話就要把整段重新處理（又慢又貴）。現在 Claude Code 會在快過期前（約 54 分鐘）先把對話壓縮成摘要，等於在 cache 失效前先「存檔瘦身」。`CLAUDE_CODE_DISABLE_FILE_MENTIONS` 也是同一思路：`@` 大檔案時不再整份灌進 context，改由 agent 按需讀取。

安全面則有一串小但關鍵的修補：MCP 權限規則改成完整名稱比對（避免前綴誤放行）、connector 不跟隨 redirect（防止被導向惡意端點）、`UserPromptSubmit` hook 提前到 skill 展開前執行（擋 prompt 就連內嵌 shell 一起擋）、resume 指令改用 ID（防止 session 名稱夾帶指令被貼上執行）、不再建議 `git add .`（避免 `.env` 外洩）。可以想像成前端在做 CSP 與 input sanitization：每個點單看都小，合起來才是完整的防線。

**前端工程師實際應用：**
- **跟你工作的關聯：** 前端專案常有又長又雜的 session（一邊改元件、一邊跑測試、一邊查 log），很容易累積到幾十萬 token；idle compaction 讓你午休或開會回來繼續工作時，不會因 cache 過期付出整段重算的時間與用量。
- **具體場景：** 你在 Next.js monorepo 裡 `@apps/web/package-lock.json` 或 `@dist/bundle.js` 這種巨大檔案，以前會直接吃掉大量 context；設定 `CLAUDE_CODE_DISABLE_FILE_MENTIONS=1` 後只傳路徑，Claude 會用 Read／Grep 只看需要的部分。另外如果你的 `settings.json` 有寫 `mcp__playwright` 之類的 allow rule，升級後記得確認名稱是完整 server 名稱（或用 `mcp__<server>__*`）。
- **這週可以嘗試：** 升級到 2.1.299 後跑一次 `/usage`，看看有沒有出現 max effort、常駐 context 或大型工具結果的警告；再檢查 `.claude/settings.json` 的 MCP allow rules，把縮寫的 server 名稱改成完整名稱，避免升級後權限規則失效。
