## Claude Code · Changelog

**版本號 / 日期：** 2.1.161 / June 2, 2026

**變更項目：**
- `OTEL_RESOURCE_ATTRIBUTES` 值現在作為 metric datapoints 的 label 附加，可依 team 或 repo 等自訂維度切分 usage metrics（OpenTelemetry 自訂維度支援）
- `claude agents` 的 row 在工作 fan-out 時現在顯示 `done/total` 進度，peek 顯示執行最久的項目
- `/mcp` 現在將從未登入的 claude.ai connectors 收合在「Show unused connectors」後面
- 平行 tool call 改善：一個 Bash 指令失敗不再取消同批次其他 call，每個 tool 各自回傳結果
- Fullscreen 模式的剪貼簿在 Linux 上改用 `wl-copy`/`xclip`/`xsel`，同時寫入 clipboard 和 PRIMARY selection（支援滑鼠中鍵貼上）
- 修復多個 bug：`/effort` dialog、workflow animations、prompt keyword shimmer 未遵守「Reduce motion」設定；`forceLoginOrgUUID` 阻擋第三方 provider session（Bedrock、Vertex、Foundry）的 regression；background subagent output 污染 `claude -p` stdout；`/usage-credits` 對 admin 觸發 re-login；`/autofix-pr` 在 git worktree 內誤報 default branch 錯誤；Windows hooks 呼叫 bash 時失敗；OpenTelemetry log events 在初始化前靜默丟失；`claude mcp` list/get 輸出 secrets；Workflow agents 在 background session 中無法編輯自己 worktree 的檔案；background sessions 使用 stale model；等多項修復

**核心概念（簡單說）：**
本次更新以 bug fix 為主，重點改善了 OpenTelemetry 可觀測性（metrics 現在可按自訂維度切分）、平行工具執行的錯誤隔離性（一個失敗不影響其他），以及多個 background session 和 Windows 平台的穩定性問題。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你用 Claude Code 搭配自己的 telemetry 系統監控 agent 使用量，OTEL 自訂維度支援讓你可以依專案或 team 分開追蹤 token 成本
- **具體場景：** 設定 `OTEL_RESOURCE_ATTRIBUTES=project=my-app,team=frontend`，之後 Claude Code 的 usage metrics 就會帶上這些 label，可在 Grafana 或 Datadog 依維度篩選
- **這週可以嘗試：** 更新到 2.1.161（`claude update`），確認平行 tool call 的錯誤隔離是否解決了你之前遇到的 batch 中止問題

- **具體場景：** 在使用 `acceptEdits` 模式的 CI 自動化流程中，Claude 修改 `.npmrc` 或 `bunfig.toml` 時會暫停等待確認，避免意外更改影響 build pipeline

**變更項目：**
- Auto mode 現在可在 Bedrock、Vertex、Foundry 上用於 Opus 4.7 和 Opus 4.8，透過設定 `CLAUDE_CODE_ENABLE_AUTO_MODE=1` 啟用

**核心概念（簡單說）：**
Auto mode 原本只在 Anthropic 直接 API 上支援，現在擴展到三大雲端平台（AWS Bedrock、Google Vertex AI、Microsoft Azure Foundry）。Auto mode 讓 Claude 自動判斷哪些操作需要使用者確認、哪些可以直接執行，大幅減少互動摩擦，適合自動化流程。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你的公司使用 Bedrock 或 Vertex 作為 Claude 的存取管道（常見於企業因 data residency 要求），現在也可以在 CI/CD 或自動化 agent 流程中啟用 auto mode
- **具體場景：** 在 GitHub Actions 中使用 Bedrock 呼叫 Claude Code 做 PR review 時，設定環境變數 `CLAUDE_CODE_ENABLE_AUTO_MODE=1`，讓 agent 自動執行不需要人工確認的步驟
- **這週可以嘗試：** 若使用 Bedrock/Vertex，加上 `CLAUDE_CODE_ENABLE_AUTO_MODE=1` 執行一次任務，觀察 auto mode 如何自動決策哪些步驟需要確認
