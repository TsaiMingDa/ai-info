> The Claude Security plugin for Claude Code is now available in beta.
>
> Scan your changes for vulnerabilities before you commit, or run a full scan across your codebase, all from your terminal on the Claude inference you already run.

**繁中改寫：**
Boris Cherny 轉發了 Claude 官方帳號的貼文：Claude Code 專用的 Claude Security plugin 現已推出 beta 版。你可以在 commit 之前掃描這次變更有沒有漏洞，或是對整個 codebase 跑一次完整掃描，全部都在終端機裡完成，用的還是你原本就在付費的 Claude 推理額度。

**核心概念（簡單說）：**
這是把「資安掃描」這件事直接塞進開發者每天用的工具鏈裡，而不是另外開一個獨立的資安產品。傳統上 SAST（Static Application Security Testing）掃描工具通常是 CI pipeline 裡的一個外部服務，開發者要等 CI 跑完才看得到結果；Claude Security plugin 的做法是讓 Claude Code 本身具備「看得懂程式碼語意、也看得懂常見漏洞模式」的能力，在你打字的當下或 commit 前就先幫你抓出問題，而且因為是同一個模型在跑，掃描邏輯可以理解程式碼的實際意圖，不只是比對規則庫。

**前端工程師實際應用：**
- **跟你工作的關聯：** 前端常見的漏洞像 XSS、不安全的 innerHTML 使用、缺少輸入驗證，很多時候是在 PR review 時才被抓到，這個 plugin 可以把檢查點往前移到你本地開發階段。
- **具體場景：** 假設你在 React 專案裡新增一段用 `dangerouslySetInnerHTML` 渲染使用者輸入的程式碼，commit 前跑一次掃描就能提早發現這是潛在的 XSS 風險，而不用等到 code review 才被同事點出來。
- **這週可以嘗試：** 找一個現有專案，安裝 Claude Security plugin beta 版，對整個 codebase 跑一次完整掃描，看看有沒有意外抓到你以為早就處理過的資安債。

## claudeai · Anthropic Blog

**原文網址：** [https://www.anthropic.com/news/anthropic-economic-index-connector](https://www.anthropic.com/news/anthropic-economic-index-connector)

**原文：**
> People have hard questions about AI and work: which jobs will change, which tasks are being automated, and what it means for their own field. The Anthropic Economic Index exists to help answer them with real data. Today we're launching the Anthropic Economic Index connector for Claude, which lets anyone explore that data directly.
>
> Getting started takes about a minute. In claude.ai, open the connectors menu, find the Anthropic Economic Index in the directory, and enable it—it works in any conversation with any Claude model, and there's nothing to install.

**繁中改寫：**
Anthropic 推出了「Anthropic Economic Index」的 connector，讓任何人都能直接在 Claude 對話中查詢這份追蹤 AI 如何被實際使用在經濟活動中的公開資料集。啟用方式很簡單：在 claude.ai 打開 connectors 選單，在目錄裡找到 Anthropic Economic Index 並啟用，不需要額外安裝，任何模型的對話都能用。啟用後就可以直接問 Claude「哪些職業最常用 AI」、「某個州的人最常拿 Claude 做什麼」等問題，答案會直接根據 Index 的真實資料回答。

**核心概念（簡單說）：**
這其實是把一份原本需要自己下載、自己分析的資料集，包裝成一個可以用自然語言查詢的 connector。技術上跟 RAG（Retrieval-Augmented Generation）的概念類似——Claude 不是憑印象回答，而是即時去撈 Index 的底層資料回答你的問題，並且會附上資料來源與限制說明，避免你把「Claude 使用模式」誤當成「整體勞動市場現況」。

**前端工程師實際應用：**
- **跟你工作的關聯：** connector 這種「把外部資料源包裝成可對話查詢介面」的模式，跟你在做企業內部工具、內部資料儀表板時可能會遇到的需求很像。
- **具體場景：** 如果你的公司也有一份內部資料集（例如使用者行為分析、A/B test 結果），可以參考這個 connector 的設計思路：與其做一個獨立的查詢 UI，不如讓 Claude 直接串接這份資料，讓非工程背景的同事也能用自然語言問問題。
- **這週可以嘗試：** 在 claude.ai 啟用這個 connector，實際問幾個關於「前端工程師」或「軟體開發」相關職業的 AI 使用問題，感受一下這種資料查詢體驗，作為未來設計類似內部工具的參考。

## Claude Code · Changelog

**版本號 / 日期：** 2.1.218 / July 22, 2026

**變更項目：**
- Changed `/code-review` to run as a background subagent, so review work no longer fills your conversation and keeps stacked slash commands as its review target（`/code-review` 改為以背景 subagent 執行，review 過程不再占用你的對話內容，且會把疊加的 slash command 當作審查對象）
- Fixed `/ultrareview` failing on descriptive arguments like "review my auth changes" — they now run a review of your current branch with the text applied as a note to the findings（修正 `/ultrareview` 在帶有描述性參數如 "review my auth changes" 時會失敗的問題，現在會對目前分支跑審查，並把該文字當作附註加進結果）
- Fixed `/code-review ultra` silently running a local review in non-interactive sessions — it now launches the cloud review（修正 `/code-review ultra` 在非互動 session 中會默默改跑本機審查的問題，現在會正確啟動雲端審查）
- Fixed Windows paths with `\u`-prefixed segments (like `C:\Users\unicorn`) being corrupted into CJK characters in tool inputs, which made those files inaccessible（修正 Windows 路徑中含 `\u` 開頭片段（如 `C:\Users\unicorn`）在工具輸入中被誤譯成中日韓文字元、導致檔案無法存取的問題）
- Fixed the left arrow key discarding the conversation with no undo: presses right after editing now ask to confirm, and Esc in the agent view returns to the conversation it backgrounded（修正左方向鍵會直接丟棄對話且無法復原的問題：編輯後立即按下時會先詢問確認，agent 檢視畫面中按 Esc 會回到被背景化的對話）
- Added HTTP status and error text to `claude mcp list` and `/mcp` when a server fails to connect, and a warning for MCP config values with hidden leading or trailing whitespace（`claude mcp list` 與 `/mcp` 在伺服器連線失敗時會顯示 HTTP 狀態碼與錯誤文字，並針對 MCP 設定值中隱藏的前後空白顯示警告）
- Fixed multi-line paste collapsing into one line with `j` in place of newlines in terminals that encode pasted newlines as Ctrl+J（修正在會把貼上的換行編碼為 Ctrl+J 的終端機中，多行貼上內容會被壓縮成一行、換行處變成字母 `j` 的問題）
- Changed `/deep-research` to start only when invoked manually; Claude no longer launches it on its own（`/deep-research` 改為只能手動觸發，Claude 不會再自行啟動它）
- Changed skills with `context: fork` to run in the background by default; opt out per skill with `background: false`（設有 `context: fork` 的 skills 預設改為在背景執行，可用 `background: false` 針對個別 skill 取消）
- Fixed remote sessions continuing to send heartbeats after their worker was replaced, which left long-lived desktop and IDE processes retrying a rejected request every few seconds forever（修正遠端 session 在 worker 被替換後仍持續發送心跳的問題，避免長時間執行的桌面與 IDE 程序無限重試被拒絕的請求）

**核心概念（簡單說）：**
這次更新的重點集中在讓 code review 相關的 slash command（`/code-review`、`/ultrareview`）變得更可靠、不干擾主對話，以及修掉一批跟終端機輸入輸出、Windows 路徑編碼、遠端 session 心跳有關的邊角案例 bug。整體方向是讓 Claude Code 在長時間、多任務並行的使用情境下更穩定，減少因為背景程序異常而卡住或重試爆量的狀況。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你有在用 `/code-review` 或 `/ultrareview` 做 PR 前自我審查，這次修正讓這些指令的行為更符合預期，尤其是帶文字描述參數時不會再失敗。
- **具體場景：** 在 Windows 機器上開發、路徑中包含使用者名稱等非 ASCII 相關片段時，先前可能遇過檔案路徑被搞亂讀不到的狀況，這次已修正。
- **這週可以嘗試：** 升級到 2.1.218 後，實際跑一次 `/code-review ultra` 搭配描述性文字（例如 "review my form validation changes"），確認雲端審查有正確被觸發。
