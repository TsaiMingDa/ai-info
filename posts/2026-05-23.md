## claudeai · Anthropic Blog

**原文網址：** https://www.anthropic.com/research/glasswing-initial-update

**原文：**
> Last month, we launched Project Glasswing, our collaborative effort to secure the world's most critical software before increasingly capable AI models can be turned against it.
>
> Since then, we and our approximately 50 partners have used Claude Mythos Preview to find more than ten thousand high- or critical-severity vulnerabilities across the most systemically important software in the world. Progress on software security used to be limited by how quickly we could find new vulnerabilities. Now it's limited by how quickly we can verify, disclose, and patch the large numbers of vulnerabilities found by AI.
>
> After one month, most partners have each found hundreds of critical- or high-severity vulnerabilities in their software. Collectively, they've found more than ten thousand. Several have told us that their rate of bug-finding has increased by more than a factor of ten. Cloudflare has found 2,000 bugs (400 of which are high- or critical-severity) across their critical-path systems, with a false positive rate that Cloudflare's team considers better than human testers.
>
> The UK's AI Security Institute reports that Mythos Preview is the first model to solve both of their cyber ranges (simulations of multistep cyberattacks) end to end. Mozilla found and fixed 271 vulnerabilities in Firefox 150 while testing Mythos Preview—over ten times more than they found in Firefox 148 with Claude Opus 4.6. XBOW reports that Mythos Preview is a "significant step up over all existing models" on its web exploit benchmark.
>
> For the last few months, Anthropic has used Mythos Preview to scan more than 1,000 open-source projects. So far, Mythos Preview has found what it estimates are 6,202 high- or critical-severity vulnerabilities in these projects. 1,752 of those have been assessed by independent security research firms: 90.6% (1,587) proved to be valid true positives, and 62.4% (1,094) were confirmed as high- or critical-severity.
>
> The relative ease of finding vulnerabilities compared with the difficulty of fixing them amounts to a major challenge for cybersecurity. Models with similar cybersecurity skills to Mythos Preview will soon be more broadly available. There is a clear need for a larger effort across the software industry to manage the volume of findings that these models will generate.
>
> To begin, we've released Claude Security in public beta for Claude Enterprise customers. In the three weeks since launch, Claude Opus 4.7 has been used to patch over 2,100 vulnerabilities. We've also begun our Cyber Verification Program, which allows security professionals using our models for legitimate cybersecurity purposes to do so without certain safeguards designed to prevent cyber misuse.
>
> The speed of AI progress means that models as capable as Mythos Preview will soon be developed by many different AI companies. That is why we have yet to release Mythos-class models to the public. But it's also why we began Project Glasswing: if a similarly capable model is released without such safeguards, it will soon become dramatically cheaper and easier for almost anyone in the world to exploit flawed software.

**繁中改寫：**
Anthropic 發布 Project Glasswing 的初期進展報告。在過去一個月內，Anthropic 與約 50 個合作夥伴使用 Claude Mythos Preview 模型，在全球最重要的軟體基礎設施中找到了超過一萬個高危或嚴重漏洞。

幾個亮點：Cloudflare 發現了 2,000 個漏洞（其中 400 個高危或嚴重），誤報率比人工測試還低；Mozilla 在 Firefox 150 中找到並修復了 271 個漏洞，是使用 Claude Opus 4.6 時的十倍以上；英國 AI 安全研究院指出，Mythos Preview 是第一個能從頭到尾解決他們兩個網路攻擊模擬情境的模型。

在開源軟體掃描方面，Anthropic 掃描了 1,000 多個開源專案，Mythos Preview 估計找到了 6,202 個高危漏洞，人工驗證後真陽性率高達 90.6%。

目前的瓶頸已從「找漏洞」轉移到「修漏洞」——開源維護者已被大量漏洞報告淹沒，甚至有些人請求 Anthropic 放慢揭露速度，因為他們需要時間設計修補程式。

Anthropic 同時宣布：Claude Security 公開測試版（供 Enterprise 客戶使用）在三週內已協助修補超過 2,100 個漏洞；Cyber Verification Program 讓合法的資安專業人員（漏洞研究、滲透測試等）可在不受某些安全限制的情況下使用模型。

**核心概念（簡單說）：**
Project Glasswing 是 Anthropic 主導的開源軟體安全掃描計畫，核心工具是 Claude Mythos Preview——一個目前尚未公開發布的超強力安全模型。一個月內，它在全球最重要的軟體中找到了超過一萬個嚴重漏洞，效率是傳統人工測試的十倍以上。

這篇文章揭示了一個現實：AI 發現漏洞的速度已經遠遠超過人類能修補漏洞的速度。現在的問題不是「能不能找到漏洞」，而是「找到了能不能及時修好」。Anthropic 還沒有把 Mythos Preview 開放給一般用戶，是因為這種能力一旦落入惡意手中，會讓攻擊者找到並利用漏洞的成本驟降。這也是 Glasswing 計畫存在的根本原因：先幫防守方建立優勢，再考慮公開發布。

**前端工程師實際應用：**
- **跟你工作的關聯：** 你在日常開發中依賴大量開源套件（npm, GitHub Actions, CDN 等），這些都是 Glasswing 正在掃描的範疇。你的依賴鏈可能正在出現新的 CVE，而且修補速度可能跟不上發現速度，需要主動管理升級節奏。
- **具體場景：** 使用 `npm audit` 或 GitHub Dependabot 時，未來幾個月可能會看到更多 CVE 通知（包括 wolfSSL、Firefox 等底層庫），因為 Mythos Preview 找到的漏洞正在陸續揭露。建議在 CI pipeline 加上 `npm audit --audit-level=high` 步驟，並設定 Dependabot 自動 PR。
- **這週可以嘗試：** 在你的專案跑一次 `npm audit` 或 `npx snyk test`，看目前有幾個高危漏洞；同時訂閱你主要依賴套件的 GitHub Security Advisories，確保第一時間收到修補通知。

**版本號 / 日期：** 2.1.149 / May 22, 2026

**變更項目：**
- `/usage` 現在顯示逐類別的用量明細——skills、subagents、plugins、每個 MCP server 的費用（`/usage` now shows a per-category breakdown of what's driving your limits usage — skills, subagents, plugins, and per-MCP-server cost）
- `/diff` 詳細檢視現在可用鍵盤捲動（方向鍵、j/k、PgUp/PgDn、Space、Home/End）（`/diff` detail view can now be scrolled with the keyboard）
- Markdown 輸出現在正確渲染 GFM task list checkbox（`- [ ] todo` / `- [x] done`）而非純列點（Markdown output now renders GFM task list checkboxes instead of plain bullets）
- Enterprise：新增 `allowAllClaudeAiMcps` managed setting，可同時載入 claude.ai 雲端 MCP connectors 與 managed-mcp.json
- 修正 PowerShell 的權限繞過漏洞：內建 `cd` 函式（`cd..`、`cd\`、`cd~`、`X:`）可在未被偵測的情況下更改工作目錄（Fixed a PowerShell permission bypass via built-in cd functions）
- 修正 git worktree 中 sandbox 寫入白名單覆蓋整個主 repo 根目錄的問題
- 修正 PowerShell 前綴/萬用字元允許規則未正確預先批准原生可執行檔的問題
- 修正 `/ultraplan` 與 remote session 建立在工作樹無真實變更時報錯的問題
- 修正 thinking spinner 在多次工具呼叫間維持琥珀色的問題
- 修正 collapsed Bash 輸出回報錯誤隱藏行數的問題
- 修正 slash command 參數提示截斷尾端字元的問題
- 修正 argument-hint 在 Tab 補全 skill 後不出現的問題
- 修正狀態列顯示基準 `/effort` 而非實際套用的 effort 等級
- 修正 `Ctrl+O` transcript 檢視在開啟時凍結而非即時更新的問題
- 修正編輯召回的 prompt 歷史條目後上下移動導致編輯遺失的問題
- 修正 `/config` 結束摘要誤報 auto-compact 與 theme 有變更的問題
- 修正 `/insights` 在 session-meta 檔案缺少選填欄位時崩潰的問題
- 修正 Remote Control session 重命名後 `claude --resume` 未同步本地名稱的問題

**核心概念（簡單說）：**
這次更新最直接影響日常使用的是 `/usage` 逐類別明細：你終於可以知道用量是被哪些 skills、subagents 或 MCP servers 吃掉的，方便調整配置。另外 `/diff` 終於可以用鍵盤導航，以及 GFM task list checkbox 的正確渲染，都是體驗提升的小確幸。

安全修補方面，修正了 PowerShell 的 `cd` 權限繞過問題，這對 Windows 使用者在 worktree 工作流程中的安全性有實質影響。

**前端工程師實際應用：**
- **跟你工作的關聯：** `/usage` 逐類別明細直接影響你的 Claude Code 使用預算管理；如果你大量使用 MCP servers 或 skills，現在終於可以看清楚費用來源。GFM checkbox 渲染正確也代表讓 Claude 幫你生成 TODO checklist 時，格式會更正確。
- **具體場景：** 在 Claude Code 中執行 `/usage` 查看用量分布；如果某個 MCP server 或 skill 占用過多，可以考慮調整使用頻率。另外試試 `/diff` 後用 `j/k` 鍵捲動差異內容，不必再離開鍵盤去摸滑鼠。
- **這週可以嘗試：** 執行 `/usage` 看你的用量分佈，確認是否有非預期的高耗用來源（例如某個你忘記關的 MCP server）；同時試試在 Markdown 檔案中讓 Claude 產出 `- [ ]` task list，確認渲染正確。

**版本號 / 日期：** 2.1.148 / May 22, 2026

**變更項目：**
- 修正 Bash tool 在某些使用者電腦上對每個指令回傳 exit code 127 的問題（2.1.147 的 regression）（Fixed the Bash tool returning exit code 127 on every command for some users）

**核心概念（簡單說）：**
2.1.147 引入了一個嚴重的 regression：部分使用者的 Bash tool 對所有指令都回傳 exit code 127（command not found），導致 Claude Code 幾乎無法執行任何 shell 指令。這個緊急修補版本專門修復這個問題。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你在 2.1.147 升級後發現 Claude Code 無法執行 `npm`、`git`、`node` 等指令，升到 2.1.148 即可解決。
- **具體場景：** 執行 `claude --version` 確認版本；若還在 2.1.147，執行 `npm update -g @anthropic-ai/claude-code` 升級（或參考你的安裝方式更新）。
- **這週可以嘗試：** 確認你的 Claude Code 版本為 2.1.148 以上，避免遭遇 Bash exit code 127 問題。
