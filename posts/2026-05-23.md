## claudeai · Anthropic Blog

**原文網址：** https://www.anthropic.com/research/glasswing-initial-update

**原文：**
> Last month, we launched Project Glasswing, our collaborative effort to secure the world's most critical software before increasingly capable AI models can be turned against it.
>
> Since then, we and our approximately 50 partners have used Claude Mythos Preview to find more than ten thousand high- or critical-severity vulnerabilities across the most systemically important software in the world. Progress on software security used to be limited by how quickly we could find new vulnerabilities. Now it's limited by how quickly we can verify, disclose, and patch the large numbers of vulnerabilities found by AI.
>
> After one month, most partners have each found hundreds of critical- or high-severity vulnerabilities in their software. Collectively, they've found more than ten thousand. Several have told us that their rate of bug-finding has increased by more than a factor of ten. Cloudflare has found 2,000 bugs (400 of which are high- or critical-severity) across their critical-path systems, with a false positive rate that Cloudflare's team considers better than human testers.
>
> The UK's AI Security Institute reports that Mythos Preview is the first model to solve both of their cyber ranges (simulations of multistep cyberattacks) end to end. Mozilla found and fixed 271 vulnerabilities in Firefox 150 while testing Mythos Preview—over ten times more than they found in Firefox 148 with Claude Opus 4.6. XBOW reports that Mythos Preview is a "significant step up over all existing models" on its web exploit benchmark.
>
> For the last few months, Anthropic has used Mythos Preview to scan more than 1,000 open-source projects. So far, Mythos Preview has found what it estimates are 6,202 high- or critical-severity vulnerabilities in these projects. 1,752 of those have been assessed by independent security research firms: 90.6% (1,587) proved to be valid true positives, and 62.4% (1,094) were confirmed as high- or critical-severity.
>
> The relative ease of finding vulnerabilities compared with the difficulty of fixing them amounts to a major challenge for cybersecurity. Models with similar cybersecurity skills to Mythos Preview will soon be more broadly available. There is a clear need for a larger effort across the software industry to manage the volume of findings that these models will generate.
>
> To begin, we've released Claude Security in public beta for Claude Enterprise customers. In the three weeks since launch, Claude Opus 4.7 has been used to patch over 2,100 vulnerabilities. We've also begun our Cyber Verification Program, which allows security professionals using our models for legitimate cybersecurity purposes to do so without certain safeguards designed to prevent cyber misuse.

**繁中改寫：**
Anthropic 發布了 Project Glasswing 第一個月的成果報告。他們與約 50 個合作夥伴使用 Claude Mythos Preview（一個尚未公開發布的超強安全模型），在一個月內從全球最重要的軟體基礎設施中找到超過一萬個高危或嚴重漏洞。

幾個令人震驚的數字：Cloudflare 找到 2,000 個漏洞（其中 400 個高危/嚴重），誤報率還比人工測試低；Mozilla 在測試期間讓 Firefox 150 找到並修復了 271 個漏洞，是使用 Claude Opus 4.6 時的十倍以上。在開源軟體方面，掃描 1,000+ 個專案後估計有 6,202 個高危漏洞，人工驗證的真陽性率高達 90.6%。

現在的問題不是找不找得到漏洞，而是找到之後能不能及時修好。Anthropic 目前還不敢公開發布 Mythos 等級的模型，就是因為這種能力一旦落入惡意手中，全球軟體的攻擊成本會急劇下降。

同步宣布：Claude Security 公開測試版（Enterprise 限定）三週內已協助修補超過 2,100 個漏洞；Cyber Verification Program 讓持有資安職業背景的研究人員可在較少限制下使用模型做合法的滲透測試。

**核心概念（簡單說）：**
Project Glasswing 是 Anthropic 主導的全球關鍵軟體安全掃描計畫，核心武器是 Claude Mythos Preview——一個暫未公開、專為資安優化的超強力模型。

打個比方：如果傳統漏洞掃描是用手電筒找黑暗中的東西，Mythos Preview 就像開了探照燈。一個月找到一萬個嚴重漏洞，效率是以前的十倍以上。但問題來了：開發者修 bug 的速度跟不上找 bug 的速度——這就是現在整個產業面臨的新挑戰。

Anthropic 選擇「先幫防守方建立優勢」的策略：讓大型基礎設施夥伴（Cloudflare、Mozilla 等）先搶先修，然後才考慮公開更強的模型。這是一篇技術加政策的重磅更新，預示著 AI 驅動的安全掃描即將成為主流開發流程的一部分。

**前端工程師實際應用：**
- **跟你工作的關聯：** 你每天使用的 npm 套件、開源工具（Firefox、wolfSSL 等底層庫）、以及 CDN 服務背後的基礎設施，都是 Glasswing 正在掃描的範疇。未來幾個月 CVE 通知會大量增加，你的依賴管理策略需要更主動。
- **具體場景：** 當 Glasswing 找到的漏洞陸續公開揭露（CVE 發布），你的 CI pipeline 可能在某天突然噴出大量 `npm audit` 警告。建議在 CI 中加上 `npm audit --audit-level=high && exit $?` 作為失敗門檻，並設定 GitHub Dependabot 自動建立升級 PR，確保不會漏掉安全更新。
- **這週可以嘗試：** 在你目前的專案跑一次 `npm audit`，看看有多少高危漏洞；同時到 GitHub 的 Settings > Security > Dependabot alerts 確認是否已開啟自動掃描。這樣當 Glasswing 觸發的新 CVE 出現時，你的 repo 能第一時間收到通知。

**版本號 / 日期：** v2.1.149 / 2026-05-22

**變更項目：**
- `/usage` 新增逐類別用量明細：skills、subagents、plugins、每個 MCP server 的個別費用（`/usage` now shows per-category breakdown）
- `/diff` 詳細檢視支援鍵盤捲動：方向鍵、j/k、PgUp/PgDn、Space、Home/End（`/diff` detail view now scrollable with keyboard）
- Markdown 輸出現在正確渲染 GFM task list checkbox（`- [ ] todo` / `- [x] done`）
- Enterprise：新增 `allowAllClaudeAiMcps` managed setting，可載入 claude.ai 雲端 MCP connectors
- 修正 PowerShell 權限繞過漏洞（內建 `cd` 函式可繞過限制）（Fixed PowerShell permission bypass with built-in cd functions）
- 修正 git worktree 中 sandbox 寫入白名單的問題
- 修正 PowerShell 前綴/萬用字元允許規則未正確預先批准問題
- 修正 `find` 指令在 macOS 大型目錄樹導致系統 crash 的問題（Fixed `find` in Bash tool causing macOS system crashes）
- 修正 managed-settings 批准對話框凍結終端機的問題
- 修正 `/ultraplan` 與 remote session 建立時「Could not capture uncommitted changes」錯誤
- 修正 thinking spinner 在多次工具呼叫間持續顯示琥珀色
- 修正 collapsed Bash 輸出回報錯誤的隱藏行數
- 修正 slash command 參數提示截斷問題
- 修正 Tab 補全 skill 後 argument-hint 不出現的問題
- 修正狀態列顯示基準 `/effort` 而非實際套用等級
- 修正 Ctrl+O transcript 視圖凍結問題
- 修正編輯 prompt 歷史條目後上下導航導致編輯內容遺失
- 修正 `/config` 結束摘要誤報不存在的變更
- 修正 `/insights` 因缺少 session-meta 快取檔案而 crash
- 修正 Remote Control session 重命名未同步本地名稱

**核心概念（簡單說）：**
這次更新有兩個主軸：透明度提升與體驗細節修復。

透明度方面，`/usage` 現在能告訴你用量是被哪些 skills、subagents 還是 MCP servers 吃掉的，就像信用卡帳單終於有了分類明細，你可以清楚知道哪個「服務」最貴。

體驗方面，`/diff` 終於支援 vim 風格的鍵盤導航（j/k），GFM task list checkbox 也能正確渲染了——這是兩個讓輸出物更實際可用的小改進。

安全修補方面，PowerShell 的 `cd` 函式可以在不觸發權限警告的情況下改變工作目錄（繞過沙盒），這個 bypass 已被修正，對 Windows 使用者的安全邊界有實質影響。

**前端工程師實際應用：**
- **跟你工作的關聯：** `/usage` 分類明細讓你能管控多 MCP server 場景下的費用分佈；GFM checkbox 渲染正確意味著 Claude 幫你生成 TODO checklist 後可以直接放進 Markdown 文件；macOS `find` 的 crash 修復也讓大型 monorepo 的操作更穩定。
- **具體場景：** 你在前端 monorepo 中同時使用 GitHub MCP、Figma MCP、Sentry MCP，執行 `/usage` 可以看出哪個 server 佔用最多，判斷是否值得對話省略某些步驟；或在 Claude Code 中讓它幫你生成 `- [ ]` 格式的 PR checklist，存進 `.github/pull_request_template.md`，確認 checkbox 是否正確渲染。
- **這週可以嘗試：** 在下一個 Claude Code session 結束前執行 `/usage`，記錄各類別的用量分佈；然後嘗試 `/diff` 指令後用 `j/k` 鍵捲動差異內容，體驗鍵盤導航新功能。

**版本號 / 日期：** v2.1.148 / 2026-05-22

**變更項目：**
- 修正 Bash tool 對所有指令回傳 exit code 127 的問題（2.1.147 的 regression）（Fixed Bash tool returning exit code 127 on every command）

**核心概念（簡單說）：**
v2.1.147 引入了嚴重的 regression：部分使用者的 Bash tool 對所有指令回傳 exit code 127（「command not found」），等同 Claude Code 完全喪失執行 shell 指令的能力。這個緊急修補版本只做了這一件事：修好這個問題。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你在 v2.1.147 升級後遇到 `npm`、`git`、`node` 等指令全都失敗的情況，升級到 v2.1.148 即可解決。
- **具體場景：** 執行 `claude --version` 確認版本；若還在 v2.1.147，執行 `npm update -g @anthropic-ai/claude-code` 或參照你的安裝方式升級。
- **這週可以嘗試：** 確認你的 Claude Code 版本為 v2.1.148 以上，避免遭遇 Bash exit code 127 問題。
