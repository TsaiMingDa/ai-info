## Claude Code · Changelog

**版本號 / 日期：** v2.1.158 / 2026-05-30

**變更項目：**
- Auto mode now available on Bedrock, Vertex, and Foundry for Opus 4.7 and Opus 4.8 → Auto 模式現已支援 Bedrock、Vertex、Foundry 三大雲端平台，適用於 Opus 4.7 和 Opus 4.8，需以 `CLAUDE_CODE_ENABLE_AUTO_MODE=1` 環境變數開啟

**核心概念（簡單說）：**
Auto 模式讓 Claude Code 能自主判斷哪些操作需要人工確認、哪些可以直接執行，就像一個有經驗的助理知道什麼時候要自作主張、什麼時候要先問老闆。這次更新把這個功能擴展到 AWS Bedrock、Google Vertex AI、Azure Foundry 這三個主流雲端 AI 部署平台，讓企業用戶在這些環境中跑 Claude Code 的 agentic 工作流程時，也能享受到更流暢的自動化體驗。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果公司透過 AWS Bedrock 或 Google Vertex AI 存取 Claude，現在可以在這些環境啟用 Auto 模式，讓 Claude 在跑多步驟任務（例如自動化 code review、批次 refactor）時，自己決定哪些步驟需要人工確認，減少不必要的中斷
- **具體場景：** 在 CI/CD pipeline 裡用 Bedrock 跑 Claude Code 做自動化安全掃描。設定 `CLAUDE_CODE_ENABLE_AUTO_MODE=1` 後，Claude 能自主完成大多數常規檢查，只在發現高風險問題時才暫停並通知人工介入，大幅降低人工干預的頻率
- **這週可以嘗試：** 如果你的工作環境有 Bedrock/Vertex/Foundry 的 Claude 存取，在測試環境加上 `CLAUDE_CODE_ENABLE_AUTO_MODE=1`，讓 Claude 執行一個需要多個工具呼叫的任務，觀察它的自主決策行為

**版本號 / 日期：** v2.1.157 / 2026-05-29

**變更項目：**
- Plugins in `.claude/skills` directories automatically loaded, no marketplace required → `.claude/skills` 目錄下的 plugin 現在自動載入，不需要先去 marketplace 安裝
- `claude plugin init <name>` scaffolds new plugins in `.claude/skills` → 新增指令，快速在 `.claude/skills` 建立 plugin 骨架
- Autocomplete for `/plugin` arguments (subcommands, installed plugin names, known marketplaces) → `/plugin` 指令現在支援自動補全
- `claude agents`: `agent` field in `settings.json` honored for dispatched sessions; `--agent <name>` to override → `settings.json` 的 `agent` 欄位現在對 dispatched sessions 生效，可用 `--agent` 覆寫
- `EnterWorktree` can switch between Claude-managed worktrees mid-session → 可在 session 進行中切換 Claude 管理的 worktree
- Fixed right-click paste duplicating clipboard in VS Code/Cursor/Windsurf → 修正 VS Code/Cursor/Windsurf 中右鍵貼上會重複貼上的 bug
- WSL: fixed image paste, screenshot paste on Windows 11, Windows Explorer drag support → 修正 WSL 環境下的圖片貼上問題
- Improved long/resumed conversation performance → 改善長對話和恢復對話的效能
- `/terminal-setup` disables GPU acceleration in VS Code/Cursor/Windsurf → 自動停用這三個 IDE 的 GPU 加速，解決渲染問題

**核心概念（簡單說）：**
這個版本最大的亮點是 plugin 系統的大幅改進。以前要用一個 plugin，你得先去 marketplace「安裝」它；現在只要把 plugin 放在 `.claude/skills` 資料夾裡，Claude Code 就會自動偵測並載入。這讓本地開發的 plugin（例如公司內部的自訂工具）變得更容易部署和使用，就像 VS Code 的 workspace extension 一樣——放在對的地方就生效，不需要額外步驟。加上 `claude plugin init` 指令可以快速建立 plugin 骨架，整個 plugin 開發流程變得更順暢。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你有為 Claude Code 寫自訂 skill（例如公司專用的 code review checklist、設計稿轉 component 的工具），現在只要把它放在專案的 `.claude/skills/` 目錄，push 進 repo，整個團隊就能自動使用，不用每個人都手動安裝
- **具體場景：** 公司有一個內部的 design token 規範，你可以用 `claude plugin init design-tokens` 建立一個 plugin，讓 Claude 在產生 CSS 或 Tailwind class 時自動套用公司的設計系統規範。把它放在 `.claude/skills/design-tokens/`，其他工程師 clone repo 後 Claude Code 就自動載入這個 plugin
- **這週可以嘗試：** 在你的專案根目錄建立 `.claude/skills/` 資料夾，然後跑 `claude plugin init my-first-plugin`，看看產生的骨架結構，試著寫一個簡單的 skill（例如讓 Claude 在回覆時自動加上公司的 coding style 提示）
