## Claude Code · Changelog

**版本號 / 日期：** 2.1.186 / June 22, 2026

**變更項目：**
- **Added `claude mcp login <name>` and `claude mcp logout <name>`**（新增 CLI 直接認證 MCP server 的指令，不必再開互動式 `/mcp` 選單；搭配 `--no-browser` 的 stdin redirect 可在 SSH 上完成）
- **Added status filtering (press f) to the `/workflows` agent detail view**（`/workflows` 的 agent 細節畫面新增按 `f` 篩選狀態）
- **Added a "Skills" section to the `/plugin` Installed tab**（`/plugin` 已安裝分頁新增 Skills 區塊）
- **Added `teammateMode: "iterm2"` setting**（新增 iTerm2 teammate 模式，auto mode 找不到 `it2` CLI 時會警告）
- **Added "Claude Platform on AWS - refresh credentials" option to `/login`**（設定 `awsAuthRefresh` 後，`/login` 新增刷新 AWS 憑證選項）
- **`!` bash commands now trigger Claude to respond to the output automatically**（用 `!` 執行的 bash 指令，輸出現在會自動觸發 Claude 回應；想保留舊的「只放進 context、不回應」行為，可在 settings.json 設 `"respondToBashCommands": false`）
- **Fixed streaming requests failing with "Content block not found" or JSON parse errors after the machine wakes from sleep**（修正電腦從睡眠喚醒後 streaming 請求報錯）
- **Changed background subagents to surface permission prompts in the main session instead of auto-denying**（背景 subagent 的權限請求改為在主 session 跳出對話框，會顯示是哪個 agent 在問，按 Esc 只拒絕該工具，而非一律自動拒絕）
- **Changed `/review <pr>` to use the same review engine as `/code-review medium`**（`/review <pr>` 改用與 `/code-review medium` 相同的審查引擎）
- **Improved memory: the agent is now reminded to compact its MEMORY.md index when nearing the size limit**（記憶體機制：MEMORY.md 索引接近大小上限時會提醒 agent 壓縮）
- **Improved skill frontmatter: `display-name`, `default-enabled`, `fallback`, and `metadata.*` keys now accept kebab-case, snake_case, and camelCase**（skill frontmatter 欄位命名同時接受三種寫法）
- 另有大量背景 agent / subagent 面板、agent teams、權限規則（`Agent(type)` deny rules）、Markdown 渲染（`~~strikethrough~~`）等 bug 修正

**核心概念（簡單說）：**
這個版本沒有單一大功能，而是把 Claude Code 的「多 agent 協作」與「自動化流程」這兩條主線打磨得更順。最值得注意的兩點：一是 `! bash` 指令的行為改變——以前用 `!` 跑指令只是把輸出塞進對話脈絡，現在 Claude 會主動讀輸出並回應，等於把「跑一個指令、然後請 AI 解讀結果」變成一步到位；二是背景 subagent 的權限模型改良，從前背景 agent 遇到需要授權的操作會直接被自動拒絕，現在改成在主 session 彈出詢問，讓你不會因為 agent 在背景跑就漏掉重要的決策點。

其餘多半是修 streaming 中斷、面板顯示、agent teams 繼承設定等穩定性問題，對每天長時間掛著 Claude Code 工作的人來說，是「少踩雷」型的更新。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你已經把 Claude Code 當成日常開發夥伴，`! bash` 的新行為會直接改變你的互動節奏——跑 `! npm run build`、`! npm test` 或 `! git status` 後不必再手動說「幫我看一下結果」，Claude 會自動接手解讀。背景 subagent 權限改良則讓你能放心同時跑多個任務，不怕背景那支默默卡在被自動拒絕的操作上。
- **具體場景：** 前端在 debug 一個 build 失敗時，可以直接打 `! npm run build`，Claude 會自動讀取冗長的 webpack/vite 錯誤輸出並指出問題根因，省去複製貼上錯誤訊息的步驟；若你嫌它太多嘴，在專案 `.claude/settings.json` 加上 `"respondToBashCommands": false` 即可關掉。另外用 MCP 串接公司內部服務的人，現在可用 `claude mcp login <name>` 在 CI 或遠端機器上完成認證，不必開互動畫面。
- **這週可以嘗試：** 升級到 2.1.186 後，試著用 `! npm run lint` 或 `! npm test` 跑一次，觀察 Claude 自動回應輸出的新行為；如果覺得每次都回應太吵，順手在 settings.json 設 `"respondToBashCommands": false` 找到適合自己的節奏。
