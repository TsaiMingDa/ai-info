## Claude Code · Changelog

**版本號 / 日期：** 2.1.220 / July 25, 2026（非本次 digest 週期內的新版本，僅列出最近一次 update 供參考）

**變更項目：**
- Bug fixes and reliability improvements

**核心概念（簡單說）：**
這個版本主要是修正 bug、提升穩定性，沒有新增大型功能。真正的新功能集中在前一版 2.1.219（7/24），包含 Claude Opus 5 上線、sandbox 網路允許清單設定、Remote Control 相關修正等，但因為日期早於上次 digest 週期，這裡不重複列出。

**前端工程師實際應用：**
- **跟你工作的關聯：** 穩定性修正版本通常不影響開發流程，但如果你有遇到 Claude Code CLI 的 bug，可以檢查是否已被此版本修掉。
- **具體場景：** 若你在用 Claude Code CLI 時遇到 crash 或行為異常，先跑 `claude --version` 確認是否已更新到 2.1.220 以上，避免回報已修好的舊 bug。
- **這週可以嘗試：** 執行 `claude --version` 確認自己是否已在最新版，若否可更新後留意是否解決手邊遇到的小問題。
