## Claude Code · Changelog

**版本號 / 日期：** 2.1.245 / August 25, 2026

**變更項目：**
- Fixed a crash on startup on Linux distributions that ship glibc 2.44 (for example Arch Linux, CachyOS and Fedora Rawhide) — 修復在搭載 glibc 2.44 的 Linux 發行版（例如 Arch Linux、CachyOS、Fedora Rawhide）上啟動時會當機的問題

**核心概念（簡單說）：**
這是一個非常小的緊急修復版本，只處理一件事：某些採用最新 glibc 2.44 函式庫的 Linux 發行版，一啟動 Claude Code 就會直接當機。這類 glibc 版本相容性問題通常是底層系統函式庫的 ABI（應用二進位介面）變動所導致，Anthropic 很快就針對這個相容性斷裂做了修補。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你在 Arch Linux、CachyOS 或 Fedora Rawhide 這類滾動更新發行版上開發前端專案並使用 Claude Code CLI，這個修復直接決定你的工具能不能正常啟動。
- **具體場景：** 假設你剛把系統套件更新到含 glibc 2.44 的版本，隔天打開終端機執行 `claude`，發現指令一下就閃退無法使用——這正是本次修復鎖定的情境。
- **這週可以嘗試：** 執行 `claude --version` 確認版本號是否 >= 2.1.245，若不是就手動升級，尤其是滾動更新發行版的使用者建議養成定期升級 Claude Code 的習慣。

**版本號 / 日期：** 2.1.243 / August 25, 2026

**變更項目：**

Added：
- Added a Loops breakdown to `/usage`: per-loop run count, total tokens, tokens per run, and last run — `/usage` 新增 Loops 明細，可看到每個 `/loop` 任務的執行次數、總 token 數、平均每次 token 數與最後執行時間，方便揪出耗費過多資源的迴圈任務
- Added `modelPicker` setting to curate the `/model` picker with an ordered, labeled list of models — 新增 `modelPicker` 設定，可自訂 `/model` 選單顯示的模型清單與順序（含 Vertex/Bedrock ID）
- Added `promptCacheTtl` and `subagentPromptCacheTtl` settings — 新增這兩個設定，讓 API key／雲端供應商使用者可以讓主對話維持 1 小時 prompt cache，子代理仍維持 5 分鐘
- Added `modelPricing` managed setting so an organization's contracted per-model rates are used for `/cost` — 新增 `modelPricing` 受管理設定，讓企業合約價格套用到 `/cost`、狀態列與遙測費用計算，而非牌價
- Added keyless sign-in under `/login` → Anthropic Console — `/login` 新增「用 Console 帳號登入」選項，不需另外建立 API key
- Added a `Skipped sources` line to `/status` for managed settings sources present but not applied
- Added a managed marker in `/mcp` and `/plugins` for claude.ai connectors whose auth is managed by your organization
- Added a tip pointing claude.ai users to `/web-setup` for connecting GitHub
- Added a `/status` line showing whether GitHub is connected for Claude Code on the web
- Added the model (and effort level) each subagent ran on to `/tasks` and agent detail dialogs — `/tasks` 現在會顯示每個子代理跑在哪個模型、哪個 effort 等級

Fixed：
- Fixed remote MCP servers in non-interactive (`-p`) and SDK sessions never recovering after a dropped connection — 修復非互動模式與 SDK session 中，遠端 MCP 伺服器斷線後無法自動重連的問題
- Fixed MCP server sign-in from the desktop app failing with "Invalid redirect URI" on servers supporting client ID metadata documents（例如 Linear）
- Fixed auto mode staying unavailable at startup when a temporary server-side disable was cached
- Fixed auto mode tool calls being denied as "temporarily unavailable" during brief API overload
- Fixed the `/model` picker silently ignoring an Ultracode selection
- Fixed `/resume` only listing the 50 most recent sessions — 現在下滑可以載入更多
- Fixed cloud sessions resuming after a mid-turn restart with a pending hook/notification re-sent incorrectly as the prompt
- Fixed cross-session messaging silently turning off inside user namespaces and rootless containers
- Fixed text hanging outside its container losing its leading columns on repaint（例如 `/login` 的登入網址）
- Fixed spellcheck not underlining a misspelled word typed directly after an emoji
- Fixed background subagents not waking when their last background Bash task completes
- Fixed sessions going silent for 10+ minutes when the API never starts a response — 現在約 3 分鐘後會逾時重試一次
- Fixed auth/model-availability error messages rendering like model output instead of error lines
- Fixed workload identity federation in CI re-exchanging single-use tokens across jobs
- Fixed server-managed `companyAnnouncements` not showing at startup right after sign-in
- Fixed hook `if` conditions like `Bash(cat *)` misfiring on commands containing `$()` or backtick substitution
- Fixed plugin dependencies declared with a `marketplace` field never resolving via `--plugin-dir`
- Fixed `/reload-plugins` keeping the LSP tool after the last LSP plugin is disabled
- Fixed `--agents` silently ignoring invalid JSON/agent definitions — 現在會明確報錯
- Fixed `/status` showing a filename-less "Found invalid entries in:" error
- Fixed `/clear` removing the `/rename` session name even though it was kept for the new session
- Fixed Ctrl+R history search and up-arrow history breaking on malformed `history.jsonl` entries
- Fixed Ctrl+[ not leaving vim INSERT mode in terminals encoding modified keys
- Fixed local IDE connection routing through `HTTPS_PROXY` when `no_proxy` casing didn't match
- Fixed sandbox network-violation details being dropped when a blocked command still exited 0
- Fixed status line/`/usage` rate-limit percentage staying stale after window reset while idle
- Fixed `claude --teleport <session>` exiting on uncommitted changes instead of offering to stash
- Fixed `/web-setup` repeatedly asking to log in with older GitHub CLI versions
- Fixed Claude in Chrome losing connection to Claude Code after an auto-update
- [VSCode] Fixed sessions started before feature flags were fetched opening in default permission mode
- [VSCode] Fixed Focus view sections collapsing on their own during subagent tool activity

Improved：
- Improved startup time：sandbox 與 MCP 初始化不再阻塞第一畫面，裸啟動跳過子指令註冊
- Improved native install/auto-update download size：二進位檔改用 zstd 壓縮（Linux x64 從約 340MB 降到約 75MB）
- Improved usage telemetry attribution for `ANTHROPIC_AUTH_TOKEN` sessions
- Improved native binary size：內建 skill 與 prompt 文字壓縮，約再減少 2MB
- Improved memory usage of native builds：程式碼改為隨用隨載，每個 session 約省 40–70MB 記憶體
- Improved peak memory usage in long-running sessions（更早觸發垃圾回收）
- Improved `/login` over SSH 的體驗
- Improved the error when effort `xhigh`/`max` is used with thinking turned off
- Improved `/loop`：連續無事可做的喚醒會合併成一行顯示

Changed：
- Changed sandboxed Bash tool prompt to no longer list allowed network hosts — 改成直接嘗試連線並讓你核准新主機
- Changed `/model` picker 與內建 `claude-api` skill 顯示 Sonnet 5 的 $2/$10 每 Mtok 價格為標準牌價（非限時優惠）
- Changed computer use on macOS：點擊桌面、Dock 或 Finder 視窗現在需要在存取權限對話框中授權 Finder
- Changed `/model`、`/fast`、`/effort` 在 Bedrock、Vertex、Foundry 上改為立即套用而非排隊到回合結束
- Fixed `claude remote-control` exiting and stranding attached Remote Control sessions when server drops environment mid-session
- Fixed Remote Control sessions served by `claude remote-control` sometimes getting stuck after restart
- Changed cross-session messaging inbox socket to close connections with no complete line within 30 seconds
- Improved the notice when resuming a conversation whose Remote Control is held by another terminal
- [VSCode] Improved history trimming in long sessions
- [VSCode] Improved attribution of the extension's own usage telemetry

**核心概念（簡單說）：**
這是一次內容量非常大的更新，橫跨新功能、修復與體感改善三大類。重點方向有三個：一是可觀測性與成本控管（`/usage` 新增 Loops 明細、`modelPricing` 讓企業合約價正確反映在成本統計上）；二是穩定性修復（MCP 斷線重連、auto mode 誤判、session 卡住等一大串邊角案例修復）；三是效能與體積優化（原生安裝檔用 zstd 壓縮大幅縮小、記憶體使用量下降、啟動速度變快）。對日常使用者來說，這次更新讓 Claude Code 「更小、更快、更穩」，同時給企業用戶更多帳務與權限管控工具。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你常開多個 `/loop` 背景任務或長時間開著 session 開發，這次的記憶體優化與 `/usage` Loops 明細能讓你更清楚掌握資源與費用消耗；MCP 自動重連的修復也讓你接的第三方工具（如 GitHub、Linear）連線更穩定。
- **具體場景：** 假設你用 `/loop` 讓 Claude Code 每 5 分鐘檢查一次 CI 狀態，過去要花很多注意力才能發現這個 loop 是不是在瘋狂燒 token；現在打開 `/usage` 就能直接看到這個 loop 的總 token 數與平均消耗，一眼判斷要不要調整頻率。
- **這週可以嘗試：** 升級到 2.1.243 以上後，跑一次 `/usage` 看看 Loops 明細，順便檢查一下自己常用的 MCP（例如 GitHub 或 Linear 連結）是否因為這次修復變得更穩定；如果你在 macOS 上用過 computer use 操作 Finder，記得留意新增的授權對話框。
