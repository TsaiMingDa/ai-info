**版本號 / 日期：** 2.1.257 / September 1, 2026

**變更項目：**
- Added Claude Fable 5.1 (`claude-fable-5-1`), now the default Fable model — 1M context, $10/$50 per Mtok with $0.25/Mtok cache reads（新增 Claude Fable 5.1 並設為預設 Fable 模型，支援 100 萬 token context，輸入/輸出每百萬 token 分別為 $10/$50，cache read 每百萬 token 僅 $0.25）
- Added "Time format" (`timeFormat`) and `timeZone` settings for turn-end clock and transcript timestamps（新增時間格式與時區設定選項）
- Added a Containment Escape rule to auto mode so cloud metadata-credential fetches, egress evasion, and cross-tenant reach are no longer auto-approved unless expected（auto 模式新增「防逃逸」規則，避免自動核准雲端憑證竊取、規避流出限制等高風險行為）
- Added `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` to force all subagents to use the main/subagent model, ignoring per-spawn overrides
- Added session-only effort switching via `/effort` (matching `/model`'s scoping)（新增 `/effort` 的單一 session 切換模式，呼應 trq212 貼文提到的 effort 切換不再打斷 cache）
- Added a `/doctor` warning for stale sandbox mask files left by a killed session
- Added a one-time prompt in auto mode before the first file read outside the working directories, with an option to block such reads (`permissions.blockReadsOutsideWorkingDirectories`)
- Added support for gateway-supplied descriptions on discovered `/model` picker entries
- Fixed settings in a `.claude/` folder created after startup not being picked up until restart
- Fixed several permission-mode, keybinding, background-session, and Remote Control bugs（大量修正權限模式繼承、鍵盤快捷鍵、背景 session、Remote Control 連線等問題，完整清單共約 60 條）
- Improved rendering performance in long conversations: less re-render work per turn, no slowdown as replies grow, background-agent updates no longer re-render the whole screen（改善長對話下的渲染效能）
- Improved prompt input responsiveness by reducing per-keystroke rendering work
- Improved `/code-review --comment` to post findings on GitLab merge requests via `glab mr note`
- Changed `--effort` to lift a new model's default-effort hold for the session only, not permanently
- Changed `/btw` history browsing from ←/→ to Shift+←/Shift+→ (or [/])
- Changed `defaultMode: "bypassPermissions"` in project-level settings files to be ignored (must be set in user/managed settings or via `--permission-mode`)
- Changed `fable`/`best` aliases in Claude apps gateway sessions to keep resolving to Fable 5 until the gateway is configured for Fable 5.1; pick Fable 5.1 explicitly via `/model`
- [VSCode] Added account/usage section headers, a model picker pill, output style selection in command menu, and multiple fixes for third-party provider deployments and screen reader announcements
- [VSCode] Changed "Delete session" to "Archive session" with a collapsible archived-sessions group

**核心概念（簡單說）：**
這是伴隨 Fable 5.1 發布的同步大版本更新，重點有三個：(1) 把 Fable 5.1 設為預設模型並開放使用；(2) 大量安全性強化，特別是 auto 模式新增「防逃逸」規則，防止雲端憑證竊取、跨租戶存取等高風險操作被自動核准；(3) 效能與體驗優化，包含長對話渲染效能、輸入延遲、以及 effort 切換不再打斷 prompt cache（呼應上方 trq212 的貼文）。VSCode 擴充功能也同步做了不少介面與可用性改進。
