## Claude Code · Changelog

**版本號 / 日期：** 2.1.148 / 2026-05-22

**變更項目：**
- Fixed the Bash tool returning exit code 127 on every command for some users (a regression introduced in 2.1.147)（修復了 Bash tool 對部分使用者的每個指令都回傳 exit code 127 的問題，此為 2.1.147 引入的 regression）

**核心概念（簡單說）：**
2.1.148 是針對 2.1.147 的緊急 hotfix。在 2.1.147 中，Bash tool 對部分使用者執行的每個指令都回傳 exit code 127（Unix/Windows 的「指令找不到」代碼），導致 Claude Code 無法執行任何 shell 指令——不管是 `npm run build`、`git push` 還是任何 CLI 工具都被視為失敗。2.1.148 修復了這個問題，讓 Bash tool 回到正常運作狀態。

**前端工程師實際應用：**
- **跟你工作的關聯：** 如果你在 2.1.147 版本下用 Claude Code 執行任何 Bash 指令（npm、git、npx 等），可能全部都會失敗並拿到 exit code 127；升級到 2.1.148 即可恢復正常
- **具體場景：** 讓 Claude Code 執行 `npm run dev` 啟動開發伺服器，或用 `git add . && git commit -m "feat: xxx"` 提交，若 Claude 回報指令找不到（127），這正是 2.1.147 的 regression，2.1.148 已修復
- **這週可以嘗試：** 執行 `claude --version` 確認目前版本是否已達 2.1.148；若版本偏舊，用 `npm install -g @anthropic-ai/claude-code` 升級，或透過 Claude Code Desktop 的自動更新取得最新版
